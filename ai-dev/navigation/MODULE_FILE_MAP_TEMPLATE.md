# Шаблон FILE_MAP.md независимого бизнес-модуля (например planfact-smr)

**Статус:** TEMPLATE — не физическая карта готового Plan/Fact. Заполнять только после появления отдельного Git/сборки/контрактов. Не подменять карту `platform-2-core`.

```md
# <Имя продукта> — карта файлов для AI-агентов

**Репозиторий:** <URL или локальная папка>
**Проверенная ревизия:** <git SHA>
**Статус:** CONFIRMED / NOT VERIFIED
**Версия Platform Module API:** <из manifest; если не существует — PLANNED>

## Первое чтение
- Корневые AGENTS.md и FILE_MAP.md
- Текущая задача и ai-dev/CURRENT_CONTEXT.md
- Публичный контракт ядра и точная совместимая версия

## Физическая карта модуля
| Зона | Существующий путь | Публичный контракт/владелец | Тесты |
|---|---|---|---|
| Манифест, entry, mount/unmount | ... | ... | ... |

| Публичные API/RPC | ... | module-owned, tenant-scope | ... |
| Миграции и RLS | ... | module-owned DB | ... |

| README, release manifest, CHANGELOG | ... | ... | ... |

## Запреты
- Не копировать код роли/Auth/permission, master data и UI-тему ядра в модуль.
- Не импортировать внутренние файлы чужого модуля или рабочие секреты.
- Не выдавать модуль за развёрнутый, пока сборка, API и серверные тесты не подтверждены.
```

**Правило обновления:** каждое изменение публичного entrypoint/местоположения файлов в бизнес-модуле должно обновлять **карту его репозитория**. Платформенная карта меняется только если изменился общий API/способ подключения, а не при каждом внутреннем файле Plan/Fact.
