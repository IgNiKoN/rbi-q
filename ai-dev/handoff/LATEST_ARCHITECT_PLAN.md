**Решения владельца 27.10.2026:**

- стадии: проектирование · тендер · строительство · ввод · гарантия · эксплуатация;
- виды объектов: корпус · паркинг · сети · благоустройство · прочее;

**Итог для владельца:** «Компания → Проекты».
- Проекты по подразделениям; карточка проекта: код, адрес, сроки, руководитель, стадия.
- «Объекты и места»: объект (корпус…) → секция → этаж → помещение со строительным номером и номером БТИ.
- В План/Факте везде «Проект».
- Работает у компании без модулей.

**Этапы:**
1. Макеты трёх экранов + опись элементов + список деталей — **показ**, без кода.
2. `045` (подразделения, поля проекта, `object` + вид, номера, «корень = объект», перенос корней RBI, синхронизация Качества). PGlite up/down побайтно; проба на сервере только чтением.
3. Детали «справочник», «карточка записи», «метка стадии» + «Образцы» + «Проекты», карточка, подразделения — **показ**.
4. «Объекты и места» (деталь «дерево мест»), место без объекта нельзя — **показ**.
5. Слово «Проект» в `src/platform`, `src/modules/planfact`.
6. `045` на боевом сервере — только по прямому разрешению. Три проверки изоляции, сверка «до / после» RBI, документы — **показ**.
