# Platform 2.0 — дорожная карта (мастер)

**Версия:** 1.0 · 20.10.2026 · утверждает владелец продукта.
**Суть:** это **та же дорожная карта RBI Platform · Construction OS** (13.08.2026, сохранена без изменений: [`reference/legacy/RBI_PLATFORM_DEVELOPMENT_ROADMAP_2026-08-13.md`](reference/legacy/RBI_PLATFORM_DEVELOPMENT_ROADMAP_2026-08-13.md)), доработанная до **мультикомпанийной SaaS-платформы**: одна оболочка, модули по подписке/роли, каждая компания изолирована. Ни один пункт старой карты не удаляется молча (v1.2 §7).

## Что изменилось по сравнению со старой картой

| Было (RBI Platform) | Стало (Platform 2.0) |
|---|---|
| Внутренняя платформа одной компании | SaaS для многих независимых компаний: `company_id` — граница данных, серверные права, RLS |
| Первый модуль — Quality, затем Construction | Первый модуль — **Plan/Fact СМР** (внешний заказчик); Quality заморожен в production (только критичные исправления) и подключится позже |
| Модули видны всем ролям одной компании | Модули по **подписке компании** + роли; лицензии и настройки — единый источник истины |
| Тендеры и бюджет — этап 4 | Часть сдвинута вперёд: **нормализация ВОР, тендерная смета, КП, КС-2** — в MVP Plan/Fact (ТЗ v1.1) |
| Фиксированная компания `rbi` в коде | Без привязки к компании; self-hosted Supabase сохраняется (сейчас — общий сервер по ADR-061) |

Последовательность после этапа Б определяет владелец по спросу клиентов: модуль подключается к той же оболочке, тем же компаниям, локациям, подрядчикам и видам работ.

## Каталог модулей и статус преемственности

| Модуль (старая карта) | Решение в Platform 2.0 |
|---|---|
| Quality | **адаптировать** — перенести в SaaS-модель после MVP Plan/Fact |
| Construction | **адаптировать** — переиспользовать `construction-v2` (TS) по аудиту |
| Knowledge | **переиспользовать** — общая база знаний, по компаниям |
| Settings / роли | **переиспользовать и расширить** — платформенный сервис прав, лицензий, настроек |
| AI-контур | **отложить** — после MVP, сначала подсказки сопоставления ВОР |
| Plan/Fact СМР | **новое** — первый модуль Platform 2.0 |
| Safety, Technical Decisions, Schedule | **отложить** — этап 3 |
| Budget, Contractors, Tenders, Procurement | **объединить/отложить** — смета и КП уже в Plan/Fact; остальное — этап 4 |
| Warranty, Operation, Analytics | **отложить** — этап 5 |

Подробности модулей, сценарии и бизнес-эффект — в сохранённой старой карте (разделы 5–14). При планировании нового модуля Архитектор сверяется с ней и [`reference/ARCHITECTURE_v1_2.md`](reference/ARCHITECTURE_v1_2.md) §7.
