## 1. Цель

Откройте Платформу 2.0 на телефоне (ширина ~375 px), войдите почтой (учётка с План/Фактом и «Качеством») → в План/Факте сверху слева кнопка «☰» → нажали → список «План/Факт, Качество, Компания…» → «Качество» → открылось «Качество»; там «☰» → «План/Факт» → вернулись. Закрыли и открыли приложение заново — открылся тот модуль, где были последним. На ПК всё как было (боковая панель).

## 2. Подтверждённое исходное состояние (код `main` 2495240)

- Мобильный переключатель уже есть: кнопка `#mobile-module-menu-btn` и список `#mobile-module-menu` внутри шапки `#main-header` (`index.html` ~стр. 265–280), рисует `ShellService.renderMobileModuleMenu()` (`js/core/app-shell.js` ~стр. 515–571; модули с учётом прав, `legacyModuleAllowed` для входа почтой + пункты платформы `getPlatformMenuItems()`, красные точки `paintNavBadges`). На ПК (≥768 px) скрыт, работает `#app-sidebar` (`css/style.css` ~стр. 895–945).
- **Причина ТД №174:** `showView()` модуля План/Факт прячет всю шапку: `main-header.style.display = 'none'` (`src/modules/planfact/index.ts` ~стр. 186) — вместе с ней пропадает «☰». Боковой панели на телефоне нет → выхода из План/Факта нет. Так же `switchViewNode(..., showHeader=false)` (`js/core/views.js` ~стр. 29) прячет шапку на экранах Настроек/Аналитики и т. п.; в «Качестве» это не мешает (там нижнее меню возвращает на экран с шапкой), разделы платформы («Компания», «Администрирование») — **не проверено**, проверить на этапе 1.
- Стартовый модуль после входа почтой: `goHome()` → всегда `#/planfact`, если он доступен (`src/platform/auth/entry.ts` ~стр. 83–86). Режим «Качества» помнится в `localStorage['rbi_app_mode']` (`js/modules/settings/features/app-mode-utils.js` ~стр. 452), но План/Факт — не режим `AppModeManager`, а маршрут, поэтому «последний модуль» между План/Фактом и «Качеством» сейчас не запоминается.
- Тесты меню: `src/platform/auth/__tests__/menu.test.ts`, `nav-badges.test.ts` (рендер `#mobile-module-menu`).

## 3. Объём реализации

1. На телефоне (<768 px) кнопка «☰» с тем же списком видна **на каждом экране**, где сейчас шапка скрыта (План/Факт — все подвкладки; разделы платформы; Настройки/Аналитика «Качества» — по итогам проверки этапа 1). Способ выбирает Исполнитель, но **без второго меню**: тот же `renderMobileModuleMenu`/`toggleMobileModuleMenu`/`selectMobileModule` (например, не прятать шапку целиком в План/Факте на телефоне, а показывать её узкую строку с «☰», либо вынести обёртку `.mobile-module-menu-wrap` в общую верхнюю полосу оболочки). Шапка «Качества» и ПК-вид не меняются.
2. Переход из списка в План/Факт и обратно работает и при входе почтой (пункт План/Факт — из `getPlatformMenuItems`, «Качество» — `changeAppMode('quality')`), отмечен текущий модуль; красные точки сохраняются.
3. Запомнить последний открытый модуль (План/Факт / Качество / Стройконтроль / раздел платформы) в одном месте оболочки (один ключ `localStorage`, владелец — `js/core/app-shell.js` или `src/platform/auth/entry.ts`); `goHome()` открывает его, если он ещё доступен, иначе — как сейчас. Демо-режим без входа не менять.
4. Тесты: меню видно в План/Факте на узком экране; переход туда-обратно; «последний модуль» (доступен / отключён у компании → первый доступный).

## 3а. Reuse review

- **Найдено:** `ShellService.renderMobileModuleMenu / toggleMobileModuleMenu / closeMobileModuleMenu / selectMobileModule` (`js/core/app-shell.js`), CSS `.mobile-module-menu-wrap`, `#mobile-module-menu` (`css/style.css`), `goHome()` (`entry.ts`), `rbi_app_mode`.
- **Решение:** REUSE + EXTEND. Новое меню, новые кнопки в нижнем таббаре, новый экран выбора — **не делать**.
- **UI:** те же классы кнопки и списка, светлая/тёмная тема, бренд RBI (`css/brand/rbi.css`), безопасная зона iPhone сверху; список не уезжает за край экрана 375 px.
- **Совместимость:** ПК (`#app-sidebar`, nav2, desk-topbar) — без изменений; режимы «Качества» (`rbi_app_mode`) — без изменений; Стройконтроль v2 продолжает сам показывать шапку.
