## 1. Цель

Офлайн становится **сервисом платформы**, к которому подключается любой модуль. Модуль только объявляет, что умеет без сети. После этого блока:
- **Приложение открывается сразу с правильным меню, даже если сервер завис или нет сети.** Права и меню берутся из памяти устройства, сервер проверяется в фоне; если права на сервере поменялись — меню обновляется само. Старого меню Качества и «Модуль 404» больше нет.
- **План/Факт и «Компания» без сети можно смотреть.** Показываются последние данные с пометкой «Без сети · данные на 14:32». Ввод без сети в них пока недоступен (кнопки неактивны, подсказка «Нужен интернет»). Ввод факта — P2-0064.
- Телефон держит **только нужное этому человеку**: по умолчанию по роли, в «Настройки → Данные на устройстве → Офлайн по модулям» видно размер каждого моего модуля. Там можно включить или выключить «держать без сети», выбрать фото и очистить скачанное. Неотправленное очистка не трогает.
- Новый модуль подключается одной записью в манифесте и списком «что скачать заранее». Экран и правила менять не нужно.

## 2. Подтверждённое исходное состояние (`main` `2ec8959`)

Копии на устройстве нет. Без сети — «Нужен интернет» (`need-internet.ts`, P2-0058), если код раздела не скачан, иначе пустые экраны или ошибки.
- **Факт** вносится вызовами `pf_fact_*` / `pf_add_*`, номер выдаёт сервер (`fact.service.ts`). Для ввода без сети это нужно менять → P2-0064.

Ограничение ожидания есть только у обновления входа (`REFRESH_WAIT_MS = 8000`, `auth.service.ts`).

## 3. Объём

0. **Права и меню сразу из памяти (решение владельца 29.10).**
   - При запуске приложение **не ждёт сервер**: берёт копию последнего ответа сервера этому человеку («компания + пользователь», P2-0058) и сразу строит меню, модули и маршруты.
   - Сервер спрашивается **в фоне** (`pf_my_platform`, `pf_my_profile`) с ограничением ожидания ≈ 5 с. Не ответил — копия остаётся, повтор раз в минуту (как в P2-0058).
   - Ответ совпал — ничего не меняется. Отличается — меню и маршруты обновляются на месте, без перезагрузки. Открытый сейчас модуль отозван — уход на главную с подсказкой «Доступ к разделу изменился». Сервер отклонил вход — экран «Вход».
   - Старое меню Качества и «Модуль 404» для модулей из копии **не показываются ни на миг**. Копии нет (первый вход на устройстве) — экран загрузки до ответа сервера, не старое меню.
   - Права на сервере не меняются: каждый запрос данных сервер проверяет как раньше, поэтому меню из памяти чужих данных не откроет. Срок «без связи» 14 дней (P2-0058) — как был.
1. **Контракт модуля «что умею без сети»** — поле `offline` в манифесте (пример):
   `offline: { view: true, input: [], files: false, prefetch: <функция модуля> }`.
   - `view` — смотреть без сети (копия для просмотра); `input` — какие вводы можно делать без сети (в P2-0060 у План/Факта и «Компании» — пусто; Качество / СК — `['*']`, у них свой движок); `files` — есть ли фото и PDF для выбора «заранее»; `prefetch` — что скачать заранее для «моих проектов».
   - Модуль без поля `offline` — «Только онлайн» (экран показывает это сам).
   - Описание контракта — в `MODULES.md`, раздел 3, сервис «Офлайн и синхронизация»: «как подключить модуль».
2. **Копия для просмотра — сервис платформы** (`src/platform/services/offline/`):
   - Одна обёртка для чтения: `offlineRead(module, key, fetcher)`. С сетью вызывает сервер и кладёт ответ на устройство с временем. Без сети (или сбой связи) отдаёт копию и признак «данные на ЧЧ:ММ, ДД.ММ». Если копии нет — «Нужен интернет для этого экрана».
   - Хранилище — IndexedDB с ключом **«компания + пользователь»** (правило 1). Другой пользователь на том же телефоне чужую копию не видит, выход из учётной записи её не показывает.
   - **Права:** в копию попадает только то, что сервер отдал этому человеку. Цены и сметы — только при праве `estimate`. Если с сетью выяснилось, что доступа к проекту больше нет, копия этого проекта удаляется.
   - Вводы, не объявленные в `input`, без сети неактивны с подсказкой «Нужен интернет». Ничего не теряется, потому что и не начинается.
   - Пометка «Без сети · данные на …» в шапке модуля. Копия старше 14 дней (срок входа без связи, P2-0058) — с предупреждением «данные могли устареть».
3. **Подключить План/Факт и «Компанию» на просмотр:** перевести чтения экранов на `offlineRead`. Экраны План/Факта: Сводка, Входящие, ВОР, Факт (журнал, шахматка, бригады), Смета и КС-2 (просмотр, по праву). «Компания»: проекты и объекты, места, люди и роли — просмотр.
   **Заранее (`prefetch`):** при «держать без сети» с сетью раз в сутки и по кнопке скачиваются основные экраны **моих проектов** (участие). **Стоп-условие:** различных чтений > 40 или заранее > 20 МБ на проект → заранее только Сводка, Факт, ВОР и шахматка, остальное — только то, что открывали (запись в ТД).
4. **Правило по умолчанию по роли** (чистая функция + unit), применяется, пока человек сам не поменял настройку. Выбор хранится по «компания + пользователь»:
   - **Инженер СК, прораб, мастер, подрядчик:** все мои модули с `view` — «держать без сети»; фото и PDF — «мои объекты, 30 дней» + фото **открытых замечаний** моих объектов независимо от даты.
   - **Руководитель / директор, гость:** модули — «держать без сети» (только записи, без фото); фото — «не скачивать заранее» (открытое остаётся в кэше).
5. **Автокэш файлов по выбору:** `downloadMissingCloudFiles` получает охват: `mine30` (новый) / `all30` / `all` / `none`. Уже скачанные фото **сами не удаляются**, только кнопкой «Очистить скачанное».
6. **«Данные на устройстве» → «Офлайн по модулям»** — список **моих модулей** (по правам и лицензии компании), строится по манифестам. У каждого модуля:
   - размер на телефоне: код + записи / копия + файлы;
   - «Держать без сети» (у модулей с `view`) или «Только онлайн» (без `offline`);
   - «Фото и PDF заранее: мои объекты за 30 дней / все за 30 дней / все / не скачивать» (у модулей с `files`);
   - «Очистить скачанное»: удаляет **только копии с сервера** (файлы и копию для просмотра). Неотправленные записи и фото (`isUnsentLocal`) не трогаются никогда. Перед очисткой — подтверждение с размером;
   - «Держать без сети» выключен → заранее ничего не скачивается, открытое остаётся до «Очистить». Подтверждение: «Без сети раздел покажет только то, что вы открывали».
   - Нынешние «Авто-кэш…», «Скачать последние 30 дней», «База знаний» входят в этот блок. Ничего не убирать (память `redesign-keep-all-functions`), опись «сейчас → где → что делает» — в макете.
7. **Документы:** `docs/APP_GUIDE.md` (что работает без сети и как выбрать), `CHANGELOG.md`, `FILE_MAP.md`, `MODULES.md` (сервис офлайна: контракт `offline`, статусы модулей, правило «права — копия сразу, сервер в фоне»), ТД 225 — статус; отчёт.

**Вне блока (решения владельца 29.10):** ввод факта без сети → **P2-0064**. Тяжёлые библиотеки и «загрузка при первом нажатии» → **P2-0065 «Документы и печать»** (прежний п. 4 карточки снят). ТД 313, 315, 320 (отправка Качества) → **P2-0061 «Починка отправки»**.

## 3а. Единый источник истины

- **Что модуль умеет без сети** — только его манифест (`offline`). Экран, правило и автокэш читают его, своих списков модулей не держат.
- **Что держать без сети** — одна настройка на устройстве («компания + пользователь»); по умолчанию — правило по роли от прав сервера.
- **Данные** — сервер. Копия на устройстве только для просмотра, всегда с временем. Правка копии без сети запрещена (ввод без сети — только через очередь, P2-0064).
- **Права** — сервер (`pf_my_platform`, `my_access`, `pf_my_permissions`); устройство только применяет. На устройстве — одна копия последнего ответа сервера (P2-0058): при запуске применяется сразу, ответ сервера в фоне её заменяет.
