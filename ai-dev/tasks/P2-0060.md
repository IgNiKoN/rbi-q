## 1. Цель

Телефон держит без сети **только нужное этому человеку**. Инженеру — Качество и Стройконтроль и фото своих объектов за последние 30 дней. Руководителю фото заранее не скачиваются. В «Настройки → Данные на устройстве» видно, **сколько места занимает каждый мой модуль**. Можно включить или выключить «держать без сети», выбрать, какие фото скачивать, и очистить скачанное. Неотправленное очистка не трогает.

## 2. Подтверждённое исходное состояние (`main` `75ac61c`; замер стенда 28.10.2026)

Код План/Факта, «Компании» и Админки **без прав уже не скачивается** (P2-0013, `P2_SW_ALLOWLIST`). Код Качества и СК — по `RBI_SW_ALLOWLIST` (`app.entry.js:199`).
- **Тяжёлые библиотеки** (`docx` 1,1 МБ, `html2pdf` 0,9, `xlsx` 0,9, `pptxviewjs` 0,6, `pptxgenjs` 0,5) кэшируются при установке у всех (`sw.js:145-157`) и подключаются тегами `<script>` при запуске (`index.html:73-93`).

После первой синхронизации скачивается всё (`downloadMissingCloudFiles(false, 'all')`, `sync-engine.core.js:4331-4362`, `storage-file-queue.actions.js:194`). В «Данные на устройстве» уже есть: «Исп / Свободно, МБ», переключатель «Авто-кэш облачных файлов», кнопки «Скачать последние 30 дней» и «База знаний» (`settings.render.js:265-290`, `downloadOfflineCacheScope`).
- **Роль и объекты** для правила по умолчанию: `roleFor(actions)` (`quality-bridge.ts`: manager / director / engineer / contractor / guest) и закреплённые объекты `my_access.objects` (null — все).

## 3. Объём

1. **Правило по умолчанию по роли** (чистая функция + unit-тесты):
   - **Инженер СК, подрядчик:** Качество и Стройконтроль — без сети; фото — «мои объекты, 30 дней» (закреплённые объекты; если закреплены все — все объекты за 30 дней).
   - **Руководитель / директор (только просмотр), гость:** модули — без сети (записи и код), фото — «не скачивать заранее» (открываются по сети, открытое остаётся в кэше).
   - План/Факт и «Компания» — «только онлайн» (их офлайн — этап В).
   - Правило применяется, пока человек сам не поменял настройку. Выбор человека хранится на устройстве под ключом «компания + пользователь».
2. **Автокэш файлов по правилу.** `downloadMissingCloudFiles` получает охват из правила: `mine30` / `all30` / `all` / `none`. Охват `mine30` — новый (по закреплённым объектам и дате). Уже скачанные фото **не удаляются сами** — только кнопкой «Очистить».
3. **«Данные на устройстве» → «Офлайн по модулям»:** список **только моих модулей** (по правам), у каждого:
   - размер на телефоне (код + записи + файлы);
   - переключатель «Держать без сети» (Качество, Стройконтроль). Для План/Факта и «Компании» — «Только онлайн», без переключателя;
   - для Качества и Стройконтроля — «Фото и PDF заранее: мои объекты за 30 дней / все за 30 дней / все / не скачивать»;
   - «Очистить скачанное» — удаляет **только загруженные с сервера файлы** этого модуля. Неотправленные записи и фото (`isUnsentLocal`) не трогаются никогда. Перед очисткой подтверждение с размером.
   - «Держать без сети» выключен → код модуля не держится в кэше, файлы заранее не скачиваются. Без сети модуль показывает «Нужен интернет» (как План/Факт в P2-0058). Рабочие записи на устройстве не удаляются.
   - Нынешние «Авто-кэш…», «Скачать последние 30 дней», «База знаний» входят в этот блок. Ничего не убирать (память `redesign-keep-all-functions`): опись «сейчас → где → что делает» в макете.
4. **Тяжёлые библиотеки при первом использовании — только если безопасно.** Перенести `docx`, `html2pdf`, `pptxgenjs`, `pptxviewjs` (и `xlsx`, если нет вызовов при запуске) из тегов `<script>` и предкэша в загрузку при первом вызове (один помощник `ensureLib(name)`). После первого использования библиотека в кэше и работает без сети. **Стоп-условие:** точек вызова у библиотеки больше 5 или она нужна при запуске → оставить как есть, запись в ТД.
5. **Документы:** `docs/APP_GUIDE.md` (что держится без сети и как выбрать), `CHANGELOG.md`, `FILE_MAP.md`, `MODULES.md` (сервис «Офлайн и синхронизация» — офлайн по модулям), ТД 225 — обновить статус, отчёт.
