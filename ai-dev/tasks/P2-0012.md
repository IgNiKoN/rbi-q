## 1. Цель

ПТО загружает в «ВОР» файл заказчика со столбцом «Вид»: строки **«КВР»** — итог вида работ заказчика (номер, объём для сверки, цена = сумма ÷ объём формулой), строки **«Номенклатура»** — сами работы с ценой материала и работы. Платформа сама понимает: КВР → группа (в план, факт и деньги **не идёт**), Номенклатура → позиции плана/факта/КС-2, каждая строка отдельно, с пояснением из «Комментария»/«Характеристики». Сверка «Σ работ одного названия и ЕИ под КВР = объём КВР» — расхождения жёлтым. КП и КС-2 выгружаются в тот же файл заказчика.

**Схема (как во всём ВОР, `specs/2026-10-20-vor-normalization-design.md`):** ВОР заказчика → **нормализация** в наши производственные позиции (место + вид работ из справочника + ЕИ, связка со строкой заказчика) → прораб и сводка работают только с позициями → **обратная сборка** КП и КС-2 через связки в строки и форму заказчика (Σ наших позиций = Σ строк заказчика). Здесь: КВР — группировка заказчика (только для сверки и обратной сборки, в производство не идёт); Номенклатура → позиции **1:1** (решение владельца 22.10.2026: «по видам работ 1:1»; слияние одинаковых работ из разных КВР не делаем — обратная сборка точная, без долей); разнесение по корпусам/этажам — блоком «прораб: шахматка, разнесение по этажам».

## 2. Подтверждённое исходное состояние (22.10.2026, только чтение)

- Файл владельца: лист «Шаблон Excel», шапка — строка 16 (`УИД строки | № | Код НСИ ОС | Объект строительства | Период обеспечения | Комментарий | Статья бюджета | Вид | Наименование работ и затрат | Характеристика | Кол-во | Ед.изм. | Цена | Сумма | Примечание | Стоимость материала на ед. изм., руб в т.ч. НДС | Стоимость работ на ед. изм., руб в т.ч. НДС | …`); 16 строк «КВР», 41 «Номенклатура», 21 пустая; у КВР `Цена = Сумма ÷ Кол-во`, `Сумма = SUMIF(Вид = "Номенклатура")`, у Номенклатуры `Цена = материал + работа`, `Сумма = Цена × Кол-во`. Номенклатура идёт сразу под своей КВР с тем же «№». Мест (корпус/секция/этаж) нет → «Весь объект».
- Сверка по файлу (одно название + та же ЕИ под КВР): 25 совпадают, **1 расходится** («Устройство и отделка откосов» 1 061,1 м² → «Окраска откосов» 13,08 м²); строки другой ЕИ («Плинтус потолочный», пог. м под м²) — не сверяются.
- Сегодня разбор (`src/modules/planfact/vor/parse.ts`) знает колонку типа только с буквами Г/Р/М; «КВР»/«Номенклатура» не распознаются → обе строки — работы, **объём задваивается** (240 280 вместо 160 015 по сумме объёмов файла).
- Позиции при подтверждении — **по одной на строку-работу** (`pf_vor_confirm`, 007), тип строки `group` в `vor_source_rows` есть; КП в форме заказчика пишет цены в колонки «за ед. материал / работа / итого» и суммы (`estimate/kp.ts`); КС-2 в форме заказчика — шаблон акта (P2-0008b).

## 3. Объём реализации

1. **Разбор:** колонка «Вид» со значениями «КВР»/«Номенклатура» (и близкие написания) — тип строки: КВР → `group` с объёмом и ЕИ (для сверки), Номенклатура → `work`; связь Номенклатуры с её КВР (тот же «№» / ближайшая КВР выше); «Комментарий» и «Характеристика» — в описание строки (видно в ВОР, Факте, КС-2); колонки «Стоимость материала / работ на ед.» — цены файла (материал / работа). Профиль формы запоминается как у других форм.
2. **Сверка:** для каждой КВР — Σ объёмов Номенклатуры одного названия и той же ЕИ = объём КВР (допуск 0,01); расхождение — жёлтая строка и счётчик «расхождений N» на шаге проверки; подтверждение ВОР не блокируется (решение владельца).
3. **План / факт / деньги:** КВР в позиции, план ₽, факт, сводку, КС-2 не входят; каждая строка Номенклатуры — своя позиция с пояснением (две «Штукатурки стен» с разным описанием — две позиции); вид работ подбирается как сейчас (словарь), различие — по пояснению.
4. **КП в форме заказчика:** у строк Номенклатуры — «Стоимость материала / работ на ед.»; ячейки с формулами заказчика («Цена», «Сумма», строки КВР) **не перезаписываются** — их пересчитывает Excel; файл открывается в Excel без восстановления, итог КВР = Σ Номенклатуры.
5. **КС-2 в форме заказчика:** строки Номенклатуры — объёмы и цены по договорной КП; КВР — как в файле (формулы).
**Вне блока:** редакции ВОР (P2-0006b); места по этажам для такого файла (в нём их нет); вход и модули (P2-0013).
