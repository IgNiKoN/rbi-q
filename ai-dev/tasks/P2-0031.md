## 1. Цель

Администратор платформы в «Админ платформы» у компании видит **5 выключателей**: План/Факт, Качество, Стройконтроль, База знаний, ИИ-помощник. Выключил — модуль пропал из меню сотрудников этой компании при входе по почте, и сервер его не обслуживает; включил — вернулся. «База знаний» работает при входе по почте. Старая плашка «Модули платформы» (хранилась в браузере) убрана. Заодно — исправление сторожа заявок `037a` (ТД №206), без которого нельзя проводить день переключения.

Проверка владельцем: «откройте Админ платформы → компания Демо → выключите Базу знаний / ИИ-помощник → войдите сотрудником Демо по почте — пунктов нет; включите — есть. У RBI всё включено, всё как раньше».

## 2. Подтверждённое исходное состояние
