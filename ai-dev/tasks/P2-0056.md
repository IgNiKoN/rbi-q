## 1. Цель

Администратор перетаскивает на экран «Объекты и места» Excel со списком помещений (наш шаблон или квартирографию заказчика) → экран сам узнаёт столбцы (корпус, секция, этаж, помещение, номера, площадь, комнаты) и показывает предпросмотр «светофором»: что будет создано, что уже есть, где ошибка → «Создать» одной кнопкой заводит всё дерево (недостающие корпуса, секции, этажи, квартиры с номерами, площадью и комнатами) → плашка «Создано N мест · Отменить». У квартиры в карточке появляются «Площадь, м²» и «Комнат».

## 3. Объём

1. **Сервер (миграция `050_places_import`):**
   - `core.locations` + `area numeric(10,2)` (> 0) и `rooms smallint` (0 = студия, до 20) — **только у `apartment`** (проверка в таблице); комментарии.
   - `pf_save_place` — **расширить** необязательными `p_area`, `p_rooms` (прежний вызов работает так же, побайтно тот же результат); `pf_project_places` — вернуть `area`, `rooms` (смена `returns table` → пересоздание; `down` возвращает прежнюю).
   - `pf_import_places(p_project uuid, p_batch uuid, p_rows jsonb, p_dry_run boolean) returns jsonb` — строки `{row_no, object, section, floor, name, build_no, bti_no, area, rooms}` (названия уже приведены клиентом: «Секция 1», «Этаж 3», «Кв. 45»). Путь ищется по `canonical_key` на каждом уровне; **есть — не трогать** (в ответе `existing`, а если в файле номера / площадь иначе — `differs`, не меняется); нет — создать (объекта нет — новый объект вида «корпус»). Секции может не быть (этаж прямо под объектом). Ответ: `{created: {objects, sections, floors, apartments}, existing, differs: [...], errors: [{row_no, msg}], ids: [...]}`. **Ошибка хоть в одной строке → ничего не пишется.** `p_dry_run = true` — тот же ответ без записи (предпросмотр «уже есть» считает сервер — один источник истины). Повтор с тем же `p_batch` — прежний ответ, ничего нового. Ограничение — 5000 строк. Номера квартир: `build_no` из файла, иначе следующий строительный номер объекта (`next_build_no`). Права — `core.require_places_manage`; журнал `log_admin_change` (`IMPORT`, батч, счётчики).
   - `pf_import_undo(p_batch uuid) returns int` — пометка удаления мест, созданных этим батчем (как `pf_remove_place`, одним действием, чтобы `pf_restore_place` мог вернуть); журнал `IMPORT_UNDO`. Только своя компания и право.
   - `down` — побайтно схема до миграции (столбцы `area`, `rooms` снимаются вместе с данными — указать в release-plan).
2. **Сервис Excel платформы:** читатель `xlsx-reader.ts` переносится в `src/platform/services/excel/` (адаптер по правилу каталога §3); `vor/xlsx-reader.ts` реэкспортирует его — экран «ВОР» и его тесты не меняются.
3. **Разбор списка помещений** (`src/platform/company/places-import.ts`, чистые функции + unit):
   - поиск строки заголовка и ролей столбцов по подписям: корпус / дом / объект; секция / подъезд; этаж; квартира / помещение / № кв.; стр. №; № БТИ; площадь (общая — если площадей несколько, выбрать «общая», остальные — «не брать»); комнат / комнатность / тип («1к», «2К», «студия» → 0, «евро-2» → 2);
   - приведение: «3» → «Этаж 3», «-1» → «Этаж -1», «1» → «Секция 1», «45» → «Кв. 45» (если в файле «оф. 2», «кл. 15» — название как в файле, вид `apartment`); пустая ячейка корпуса / секции / этажа — значение сверху (объединённые ячейки и «лесенка»);
   - **шаблон** «Скачать шаблон» (`buildRegistryXlsx`): Корпус | Секция | Этаж | Помещение | Стр. № | № БТИ | Площадь, м² | Комнат + 3 строки-примера.
4. **Экран (в `ObjectsPlaces.ts`, вид — токены «Стандартной» темы, компоненты `Sheet`, `Toast`, таблица реестра):**
   - **ПК:** файл .xlsx, брошенный на область дерева, подсвечивает её («Отпустите — загрузим список помещений»); брошенный на строку объекта — этот объект по умолчанию для строк без корпуса. **Телефон и ПК:** «⋯ → Загрузить из Excel» и «Скачать шаблон». Не .xlsx — подсказка «Нужен файл Excel (.xlsx)»; PDF — «PDF-планы — в следующем обновлении» (P2-0057).
   - **Предпросмотр** листом: выбор листа (если их несколько), столбцы с ролями (выпадающий список «что это за столбец», как в ВОР), итог «Будет создано: 1 корпус, 2 секции, 24 этажа, 192 квартиры · уже есть 10 · ошибок 0», таблица строк «светофором»: зелёная — новое, серая — уже есть, жёлтая — уже есть, но в файле номера / площадь иначе (не меняется), красная — ошибка с причиной (нет этажа у квартиры, площадь не число, дубль в файле, глубже 6 уровней). При красных строках «Создать» недоступна с текстом «Исправьте строки N, M в файле». Большой файл — первые 200 строк + счётчики.
   - **«Создать»** → `pf_import_places` → дерево обновляется без перезагрузки страницы, новые ветки раскрыты, плашка «Создано N мест · Отменить» (~10 с, Ctrl/Cmd+Z) → `pf_import_undo`.
   - **Карточка квартиры:** поля «Площадь, м²» и «Комнат» (правка — `pf_save_place`); в шахматке у клетки — подсказка с площадью и комнатами (вид — по макету).
   - Только онлайн (как P2-0055).
5. **Опись функций «сейчас → где → что делает»** — ни одна кнопка экрана P2-0055 не пропадает.
6. **Документы:** `MODULES.md` (§2 «Место»: площадь, комнаты, импорт из Excel; §3 «Excel»: + структура мест, сервис в `src/platform/services/excel`), `APP_GUIDE`, `CHANGELOG`, `FILE_MAP`, `UI_COMPONENTS` (лист импорта «светофор»), `GLOSSARY` (квартирография, если появится в интерфейсе), `docs/TECH_DEBT.md`, release-plan.
