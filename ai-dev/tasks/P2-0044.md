## 1. Цель

Представитель подрядчика входит, сразу видит «Мои замечания» — замечания своей фирмы, — берёт «В работу» и отмечает «Устранено» с фото; инженер принимает или отклоняет. Чужая фирма, удаление и самозакрытие — запрещены сервером.

Инженер/руководитель — как раньше.
2. **Клиент — фирма по номеру:** Стройконтроль 2.0 отбирает замечания подрядчика по `core_counterparty_id` (или доверяет отбору сервера) — без сравнения названий; `my_access` отдаёт id фирмы (если нет — добавить в ту же миграцию).
3. **Кабинет:** для роли `contractor` стартовый экран — «Мои замечания» (список Стройконтроля 2.0 своей фирмы, фильтр по статусу «к устранению / на проверке / принято»); вкладки без действий для подрядчика («Новая проверка», «План») скрыты; в форме — только «В работу», «Устранено (фото)», «Повторно предъявить»; без кнопки удаления.
4. **Проверки:** PGlite (подрядчик: своё видит, чужое — нет; удаление — отказ; `closed` — отказ; `fixed` с фото — да; инженер закрывает), REST (`rest.test.mjs`, раздел 0044), unit клиента, стенд/живой показ на тестовой компании.
