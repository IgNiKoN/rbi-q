## 1. Цель

На объекте RBI в План/Факте («Места») — те же корпуса, этажи и квартиры, что в Качестве; замечания и приёмки Стройконтроля 2.0 знают свой объект (ТД №246). Дерево ведётся в одном месте — в Качестве (шаг 1); План/Факт его видит и не правит.

## 2. Подтверждённое исходное состояние (сервер, 26.10.2026, только чтение)

- RBI (рабочая компания): места только в Качестве — `quality.location_nodes` 15 объектов, 18 корпусов, 133 этажа, 123 квартиры; `core.locations` у RBI — 0. Места План/Факта есть только у тестовых «Демо» (124) и «Альфа» (2).
- Связь «узел-объект Качества ↔ объект ядра» есть (039b, `location_nodes_object_sync`, `quality.project_objects.core_object_id`); ниже объекта — нет.
- `core.locations` (бывш. `planfact.locations`, 006 → 016): `project_id`, `parent_id`, `node_type` (building/section/floor/apartment/other), `name`, `canonical_key`, `depth`, `deleted_at`; правят функции `pf_*` (план/факт) — по правам План/Факта.
- Замечания/приёмки v2: `"locationId"` → узел Качества; `core_project_id` у всех 33 строк пуст (ТД №246) — видимость «по объекту» к ним не применяется.

## 3. Объём

1. **Пробная привязка (только чтение):** узлы Качества → объект ядра (через узел-объект) → будущие места `core.locations` (тип, родитель, глубина ≤ 6); список проблем (узел без объекта, тип вне списка, глубина, дубли имён у одного родителя) — владельцу, не угадывать.
2. **Миграция `044` (up/down):** `quality.location_nodes.core_location_id`; разовое создание мест в `core.locations` для узлов Качества (с узла-объекта вниз); триггер Качество → ядро (создание, переименование, перенос, удаление узла → то же в `core.locations`); правка мест в План/Факте у объектов, чьё дерево ведёт Качество, — отказ сервера с понятным текстом; замечаниям/приёмкам v2 — `core_project_id` по объекту узла (новые — триггером).
3. **План/Факт:** на объекте с деревом из Качества «Места» — только просмотр с пометкой «ведутся в Качестве» (кнопки правки скрыты).
4. **Проверки:** PGlite (создание/переименование/удаление узла → место ядра; отказ правки в План/Факте; v2 получают объект; видимость по объекту — подрядчик и закреплённые объекты как раньше или строже — список изменений владельцу); REST; откат побайтно.
