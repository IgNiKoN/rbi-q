## 1. Цель

ПТО загружает файл заказчика и за четыре шага (Файл → Места → Раскладка → Проверка, одна главная кнопка внизу каждого шага) получает позиции работ **с адресом до квартиры или этажа**: «Корп. 1.1 · Секция 1 · Этаж 3 · кв. 15 · Стяжка М150-75 · 50,78 м²». Сумма раскладки всегда равна строке заказчика; КС-2 собирается обратно в строки заказчика через связки с долей.

## 2. Исходное состояние (прогон разбора Архитектором 27.10.2026 на образцах, текущий `main`)

- `0_СЕБЕС … Спутник`, лист «себес уч.2 корп. 1.1»: 73 работы распознаны, **0 с местом** — все «Без указания места». Заголовки «Черновая отделка МОП 1-го этажа», «… МОП 2-7го этажей», «… квартир 2-7 этажи» читаются как группы, не как места. Стяжка 2 268,41 м² на этажи 2–7 — одной позицией на весь корпус.
- Тот же файл, листы «Расчёт 1 секции Квартиры», «Расчёт 2 секция» (секция · этаж · квартира · тип · площадь · комнаты · **объёмы по видам работ**: штукатурка, шпаклёвка, обои, ламинат, натяжной потолок, плитка СУ, откосы…) и «Расчёт 1 секции МОП» (секция · этаж · помещение · площадь) — **не используются** («не похоже на ВОР»).
- `ГПР ФСК ЗУМ …`, листы «ФКП, 142/141/109»: корпус и секция распознаются; «кв. 3, 16, 24…» и «эт. 4–13» уходят в пометку позиции на уровне секции → прорабу нечего отмечать по квартире/этажу. В «ФКП, 141» корпус не указан («Блок N») — ПТО выбирает вручную.
- Интерфейс: «Сохранить черновик» появляется только после выбора файла и только если лист распознан, внизу формы; затем «Разобрать» → Места → Виды работ → «Подтвердить ВОР» — шесть действий в разных местах экрана (`vor/VorTab.ts`, `vor/VorDraft.ts`).
- Данные: `vor_links.share` (доля 0..1) и `locations.area` уже есть; `pf_add_location(..., p_area)` принимает площадь; «Закрыть этаж целиком» (`fact/FloorClose.ts`) раскладывает по вложенным местам.

## 3. Объём

1. **Места из заголовков групп** (`vor/parse.ts`, `vor/places.ts`): «МОП 1-го этажа», «квартир 2–7 этажи», «2-7го этажей», «Секция N», «кв. …», «эт. 4–13», «Блок N»; тип места (квартиры / МОП / встроенные) — в пометку и в выбор узлов. Корпус — по названию листа (уже есть) или выбором ПТО.
2. **Лист площадей** (новый тип листа рядом с «ВОР»): узнаётся по шапке «Секция · Этаж · Квартира/Тип пом. · S»; читает квартиры и помещения МОП с площадями и, где есть, объёмами по видам работ. Профиль формы запоминает колонки листа площадей (как профиль ВОР).
3. **Дерево мест одной кнопкой**: недостающие секции × этажи × квартиры (и помещения МОП) создаются из листа площадей с площадью (`pf_add_location` с `p_area`), без «плюсиков».
4. **Раскладка** строки с диапазоном/группой на места, по порядку точности: (а) объём вида работ по квартирам из листа площадей; (б) площади мест из дерева; (в) поровну — с пометкой «нужно подтверждение ПТО». Округление 0,01, остаток — на последнюю долю, сумма = строке. Уровень: квартира, если есть площади, иначе этаж; ПТО меняет для строки. ПТО может поправить любую долю (сумма пересчитывается и проверяется).
5. **Мастер «Загрузка ВОР»** вместо текущей формы: полоса шагов сверху, одна главная кнопка внизу («Дальше: места» → «Дальше: раскладка» → «Дальше: проверка» → «Подтвердить ВОР»); черновик сохраняется сам при переходе со шага «Файл» — отдельной кнопки «Сохранить черновик» нет. Шаг «Файл» показывает, что найдено: листы ВОР, листы площадей, МОП. Светофор: 🟢 само, 🟡 подтвердить, 🔴 разобрать — ПТО видит только исключения. После подтверждения — «В этом файле есть ещё лист ВОР: корп. 1.2 — загрузить?» без повторного выбора файла.
6. **Сервер** (миграция `048`): подтверждение ВОР создаёт по строке заказчика N позиций (по местам раскладки) и N связок с долями; раскладка «поровну» без подтверждения ПТО — отказ сервера; кто и когда подтвердил раскладку — в журнале. Редакции ВОР (P2-0006b) переносят связки 1:N по совпавшим строкам.
7. **Факт и шахматка** показывают адресные позиции: этаж → квартиры; «Закрыть этаж целиком» работает по ним без изменений.

## 6. Критерии приёмки

1. На образце СЕБЕС ≥ 90 % работ получают этаж; со листом площадей — квартиры; на ФСК — квартиры из «кв. …», этажи из «эт. 4–13».
2. Сумма раскладки = строке заказчика по каждой строке; «поровну» без подтверждения ПТО — сервер не принимает.
3. На каждом шаге мастера одна главная кнопка внизу; отдельной «Сохранить черновик» нет; ничего из текущих функций не потеряно (опись «сейчас → где → что делает» в отчёте).
4. Прораб в «Факте» видит этаж → квартиры с объёмами; «Закрыть этаж целиком» работает.
5. КС-2 по строке заказчика = сумма факта по её долям.
