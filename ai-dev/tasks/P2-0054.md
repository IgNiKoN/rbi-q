## 1. Цель

Дерево мест каждой компании ведётся **в ядре**: Компания → Проект (ЖК) → Объект (корпус 1, 2, 3, паркинг, детский сад, школа…) → Секция → Этаж → Квартира/помещение. Править его можно **только** в «Компания → Объекты и места». Качество и Стройконтроль 2.0 видят те же места (выбирают их в проверках, замечаниях, приёмках, планах этажей), но не правят. Новые проекты (демо-стенд, новые компании) заводят места сразу; проекты RBI переводятся последним этапом — все проверки, замечания, приёмки, планы этажей и привязки инженеров остаются на месте.

## 3. Объём

1. **Признак проекта «кто ведёт места»** — `core.projects.places_master` (`'core'` | `'quality'`), по умолчанию `'core'`; в `048` проекты, у которых `places_led_by_quality()` истинна **и есть хотя бы одно место Качества**, получают `'quality'` (RBI, Альфа); пустые проекты — `'core'`.
2. **Ядро → Качество (зеркало):** для проекта `'core'` каждое создание / переименование / перенос / удаление места в `core.locations` отражается в `quality.location_nodes` (у нового узла `id` = id места ядра текстом, `core_location_id` = тот же id; родитель — узел-ЖК для объекта). Тип: объект любого вида → `building`, остальные типы — как есть, неизвестные → `other`/без типа (как читает Качество — проверить в этапе 1). Петли нет — флаг `quality.place_sync`.
3. **Защита:** для проекта `'core'` прямая запись в структуру `location_nodes` (создание, родитель, название, тип, удаление) — отказ сервера «Места ведутся в «Компания → Объекты и места»», кроме зеркала; синонимы и узел-ЖК (`nodeType = 'object'`, корень) — как сейчас (это проект, не место). Для `'quality'` — всё как сейчас (`044`). `places_led_by_quality(p)` = `places_master = 'quality'`; `pf_locations_from_quality` — по признаку.
4. **Виды объектов:** в `core.object_kinds` добавить «Детский сад» (`kindergarten`), «Школа» (`school`) — по примеру владельца.
5. **Качество — только выбор мест** (для проектов `'core'`): справочник мест в «Настройках» Качества — просмотр дерева + кнопка «Править в Компании» (переход в «Компания → Объекты и места»); СК 2.0 при заведении помещения **выбирает** квартиру из дерева, а не создаёт её; ошибка сервера при старой несинхронизированной правке с телефона — понятное сообщение, остальные данные очереди синхронизации не теряются. Остальные экраны Качества и СК 2.0 не меняются (решение владельца «Качество — образец»).
6. **Скрипт перевода RBI** `scripts/p2-0054/`: проба (только чтение) → снимок «до» → перевод проектов компании в `'core'` (места уже в ядре с P2-0045; дозаливка недостающих связей `core_location_id`) → снимок «после» → сверка; откат — вернуть `'quality'`.
