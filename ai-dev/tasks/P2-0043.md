## 1. Цель

Файлы старого приложения РБИ (фото проверок, библиотека, TWI, отчёты, планы, дефекты) больше не отдаются и не принимаются без входа. Качество (бакеты `quality-*`) работает как раньше.

## 2. Подтверждённое исходное состояние

- Правила `storage.objects` на сервере (26.10.2026): `Allow all for anon on <бакет>` (9 бакетов: `custom-assets`, `inspection-photos`, `library-checklists|docs|etalons|nodes|practices|twi`, `twi-pdfs`), `Public … Access Plans` (`construction-plans`, роль `public`), `construction-defects_*_anon` (`anon, authenticated`), `temp reports storage public … / authenticated …` (`reports`), `storage_*_transition` (читают `public.rbi_engineer_profiles` — причина ТД №242), `rbi_admin_storage_access` (`public.rbi_current_role()`); правила Качества `quality_files_*` и `quality_files_guard_*` (018d) — не трогать.
- Файлы старых бакетов скопированы в `quality-<бакет>/<компания>/…` при переносе (P2-0027, P2-0036; `docs/RBI_TRANSFER.md`: сверка «ссылки на старые бакеты — 0»).
- Клиент работает с бакетами `quality-*` (`companyStorage` в `src/platform/auth/quality-bridge.ts`; SW подменяет публичные ссылки `quality-*` на авторизованные — `sw-storage.test.ts`). Имена старых бакетов в `js/*` — логические, мост добавляет `quality-` — **проверить** на этапе 1.
- Признак `storage.buckets.public` у старых бакетов — **проверить** (при `public = true` файл отдаётся по `/object/public/…` в обход правил).

## 3. Объём

1. **Опись (только чтение):** бакеты (`public`, число файлов), правила `storage.objects`/`storage.buckets`, сверка «каждый файл старого бакета есть в `quality-*`» (число и имена), ссылки на старые бакеты в данных `quality` и в клиенте.
2. **Миграция `042_close_rbi_storage` (up/down):** старые бакеты — `public = false`; удалить правила старых бакетов для `anon`/`public`/`authenticated` (перечень — из описи этапа 1, правила `quality_files_*` не трогать); снять SELECT `authenticated` на `public.rbi_engineer_profiles`, выданный `041` (ТД №242), если после удаления правил её больше не читает ни одно правило других схем. Копии — `p2_backup.p2_0043_*`. Down — побайтно.
3. **Проверка:** без входа — старое фото по публичной ссылке и по API — отказ, загрузка — отказ; вошедший — загрузка/скачивание в `quality-*` работают (`test:server` 018d); приложение — фото проверок и планы показываются.
