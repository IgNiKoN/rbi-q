## 1. Цель

Первое открытие приложения на новом телефоне быстрее примерно вдвое, без изменений внешнего вида:
- сервер отдаёт код, стили и переводы **сжатыми** (gzip) — браузер распаковывает сам;
- логотип экрана загрузки весит **≈ 22 КБ вместо 1 843 КБ**, выглядит так же (сравнение показано владельцу 29.10 — «сейчас / после», телефон и ПК);
- старый логотип **сохранён в проекте**, но телефоны его больше не скачивают.

## 2. Подтверждённое исходное состояние (боевой сайт, 29.10.2026)

- **Сжатие:** `curl -H 'Accept-Encoding: gzip, br'` → `content-encoding: gzip` только у `index.html`. У `*.js`, `*.css`, `locales/*.json`, `data/*.js` — **без сжатия** (`content-length` = размер файла). `manifest.webmanifest` → `content-type: application/octet-stream`.
- **Замер холодного открытия до формы входа** (чистый браузер, 375 px, Chromium, сеть и процессор с ограничением):

  | Условия | Пустой экран | Форма входа | Скачано к показу |
  |---|---|---|---|
  | без ограничений | 0,7 с | 0,8 с | 13,4 МБ / 152 запроса |
  | 4G 9 Мбит/с, 150 мс, процессор ×4 | 8,6 с | **14,5 с** | 16,0 МБ / 212 |
  | слабая сеть 1,6 Мбит/с, процессор ×4 | 42 с | **62 с** | 12,2 МБ / 182 |
  | повторное открытие (из кэша версии) | 0,3 с | 0,9 с | 0 |

- Файлы первого экрана, на которые ссылается `index.html` напрямую: 102 файла, **8,6 МБ → 2,1 МБ в gzip** (оценка `gzip -9`). Например `sync-engine.core.js` 300 → 62 КБ, `xlsx.full.min.js` 860 → 310 КБ, `data/system_templates.js` 440 → 70 КБ.
- **Логотип:** `icons/icon-512-2.png` — PNG 1254×1254, 1 886 769 байт, без прозрачности; показывается 116×116 (`.splash-logo`, `css/style.css:31`). Ссылки: `index.html:163` (заставка), `sw.js` ≈ 636–637 (`icon`/`badge` уведомлений), `js/modules/settings/features/app-mode-utils.js:921–922` (`icon`/`badge` уведомлений), комментарий `css/brand/rbi.css:10`. Входит в опись версии (`sw.js:60`).
- Облегчённый вариант проверен Архитектором: 348×348 (×3 к размеру на экране), JPEG качество 82 → 22 872 байта; на заставке 375 и 1440 (×2) визуально не отличается.
- **nginx:** действующая настройка `/etc/nginx/sites-available/rbi-router` (блок `server_name app.rbi-q.ru`, `location /` с `add_header Cache-Control "no-cache"`), каталог сайта `/var/www/rbi-quality`; папки `ai-dev|docs|scripts|src|sql|supabase|tests|…` сайт не отдаёт (404) — `docs/SERVERS.md` ≈ 92–94. Прецедент правки — P2-0032 (`reports/P2-0032/executor-1.md`): правка файла через файловый менеджер Beget, `nginx -t` и `systemctl reload nginx` — владелец в терминале панели Beget.
- **Опись версии (P2-0066):** `scripts/app-files.mjs` — в приложение входят `css data fonts icons js libs locales` и файлы корня; `docs/` не входит. Установка версии сверяет sha-256 тела ответа (`sw.js` ≈ 435).

## 3. Объём реализации

1. **Сжатие на стенде** (`tests/offline/` — сервер стенда): режим «отдавать gzip, как будет nginx» (`content-encoding: gzip`, `vary: accept-encoding`). Прогнать установку версии и выкладку со сжатием: отпечатки совпадают, версия ставится целиком, без сети открывается.
2. **Логотип:**
   - новый файл `icons/splash-logo.jpg` (348×348, JPEG ≈ 82, ≈ 22 КБ) из `icons/icon-512-2.png`;
   - `index.html` (заставка) → `./icons/splash-logo.jpg`;
   - уведомления (`sw.js`, `app-mode-utils.js`, `icon` и `badge`) → `./icons/icon-192.png` (уже есть, 58 КБ; тянуть 1,8 МБ ради значка уведомления не нужно);
   - **старый логотип сохранить:** `git mv icons/icon-512-2.png docs/assets/splash-logo-original-1254.png` — в опись версии и на сайт (404) он не попадает; комментарий в `css/brand/rbi.css` поправить;
   - `npm run build:version` — опись без `icon-512-2.png`, с `splash-logo.jpg`.
3. **Замер «первое открытие»** — скрипт `tests/perf/first-open.mjs` (playwright-core, как стенд): адрес, профиль сети (`4g` / `slow`), процессор ×4 → пустой экран, форма входа, байты и запросы к показу, JSON в консоль. Основа для «сторожа веса» в P2-0067.
4. **Правка nginx (текст и инструкция для владельца)** — в блок `server_name app.rbi-q.ru` (не в общий `http`, API и Supabase не трогать):
   ```
   gzip on;
   gzip_vary on;
   gzip_comp_level 5;
   gzip_min_length 1024;
   gzip_types text/css application/javascript text/javascript application/json application/manifest+json image/svg+xml text/plain;
   ```
   плюс `types { application/manifest+json webmanifest; }` для `manifest.webmanifest`, если не конфликтует с `mime.types` (иначе — не делать, записать в ТД). Перед правкой — прочитать `/etc/nginx/nginx.conf` и `rbi-router` (только чтение): не задано ли уже `gzip*` (повтор директивы в том же блоке → `nginx -t` упадёт).
   **Как вносить:** как в P2-0032 — правка файла через файловый менеджер Beget (VNC искажает символы с Shift: `_`, `&`, `$`, `|` набирать в терминале нельзя), резервная копия `rbi-router.bak-p2-0067a` рядом; затем владелец в терминале: `nginx -t`, при `successful` — `systemctl reload nginx`. Правка сервера — **только после разрешения владельца** в чате.
5. **Выкладка:** после приёмки владельцем — слияние в `main`, push, `git pull` на сервере, `node scripts/check-release.mjs` (все файлы описи совпадают с отпечатком — уже со сжатием), затем правка nginx (п. 4), затем повторно `check-release` и замер `first-open.mjs` на боевом.

## 8. Риски и зависимости

- **Сверка отпечатков при сжатии** — тело после распаковки то же, но проверить на стенде (этап 1) до сервера.
- **ETag** у nginx при gzip становится «слабым» — установка версии идёт с `cache: 'reload'`, на неё не влияет; проверить `r-deploy`.
- **Старые версии у людей** (до P2-0066 и P2-0066) держат `icon-512-2.png` в своём кэше версии — после переноса файла на сайте 404 не ломает их: файл им из сети не нужен. Проверить `r-transition`.
- Повтор директив `gzip*` → `nginx -t` упадёт; поэтому сначала чтение `nginx.conf`, резервная копия, `nginx -t` до reload.
