## 1. Цель

Откройте Платформу 2.0 своей почтой → Качество → «RBI» → раздел отчётов: видите **свои старые отчёты** (столько же, сколько в старом приложении), открываете 2–3 старых отчёта (файл и сохранённую страницу отчёта) — они открываются так же, как в старом приложении. В Базе знаний **эталоны и практики** — те же, с картинками/файлами. В отчёте Исполнителя — сверка: строк старое = новое по отчётам, снимкам, эталонам, практикам; файлов по каждому бакету (`reports`, `library-etalons`, `library-practices`) — в списке = скопировано, ошибок 0. Старое приложение и его данные не изменились (отпечаток до = после).

## 3. Объём реализации

1. **Миграция** (следующий свободный номер после `033`, `NNN_rbi_transfer_reports_{up,down}.sql`): `create or replace` функций переноса — отчёты и снимки входят в перенос, `reports` — в список бакетов; сверка `quality.rbi_transfer_verify` — **дополнительно по каждому бакету** (в списке / скопировано / ошибок / суммарный размер старое = новое). `down` — возвращает тексты функций состояния `031c` (побайтно). Только новые/заменённые объекты в `quality`, `public` — только чтение.
2. **Перенос** отчётов и снимков: id сохраняются; код проекта → объект ядра (`core_project_id`, как P2-0027); `project_canonical_key` — как у остальных записей, чтобы правило видимости `033` пускало ровно тех же людей; автор — по `quality.rbi_transfer_people`. Ссылки `file_url` и ссылки внутри HTML снимков на старые бакеты → бакеты компании.
3. **Файлы** бакета `reports` → `quality-reports/<id компании>/<старый путь>` существующим `scripts/rbi-transfer/files.mjs` (докопирует только новые).
4. **Проверка практик и эталонов:** по бакетам `library-etalons`, `library-practices` — файлов старое = в списке = скопировано, размер совпадает, выборочно 5 файлов побайтно; в записях нет ссылок на старые бакеты; в приложении эталон и практика открываются с картинками.
5. **Документы:** `docs/RBI_TRANSFER.md` (убрать «отчёты не переносятся», цифры, время, день переключения), `docs/SERVERS.md`, CHANGELOG, TECH_DEBT.

## 8. Риски

- **Размер:** +1,6 ГБ базы, +1,8 ГБ файлов; в день переключения (P2-0032) очистка и перенос повторяются — время переноса вырастет (замер на этапе 1).
