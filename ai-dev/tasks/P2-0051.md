**Статус:** IN_PROGRESS (27.10.2026; решение владельца — «да делай с такими цветами всю платформу… можно даже сразу и ставим её по умолчанию (название Стандартная), темы Авто, Светлая и Тёмная, по умолчанию Авто»)

**Репозиторий:** `IgNiKoN/rbi-q`; рабочая копия `~/dev/platform-2-core-p2-0051`, ветка `task/P2-0051-standard-theme` от `origin/main` (`8f7a484`)

## Решения владельца (27.10.2026)

1. Цвета макетов (тёмная и светлая) — тема **всей** платформы, включая Качество и Стройконтроль.
2. Название темы — **«Стандартная»**; режимы **Авто / Светлая / Тёмная**; по умолчанию **Авто** (по настройке устройства).
3. Дизайн-систему платформы строить вокруг этих сочетаний.

## 1. Цель

Открываю приложение на любом устройстве — оно в теме «Стандартная» (светлая днём / тёмная, если на устройстве тёмная тема), в спокойных цветах макетов: тёмный сине-графитовый или тёплый кремовый фон, белые / графитовые карточки, золотой акцент, приглушённые зелёный и красный. В «Вид и удобство» (сейчас «Интерфейс») — «Стандартная · Авто / Светлая / Тёмная» первой строкой; прежние темы остаются в списке («Дополнительно»), ничего не удаляется.

## 3. Объём

1. `css/style.css`: темы `std-light` и `std-dark` (полный набор токенов по образцу `rbi-*-v2/v3`, включая все токены, которые используют модули: `--primary`, `--accent`, `--color-*`, тени, шапка, навигация, поля, таблицы, статусы); `std-auto` — по настройке устройства.
2. `js/services/settings.service.js` и все места выбора / применения темы (`settings.render.js` ≈ 95–110, 2155, 2430–2440, 2524–2555; `settings.actions.js`): добавить `std-auto|std-light|std-dark`, по умолчанию `std-auto`. Перенос: у кого сохранена прежняя тема по умолчанию (`rbi-auto-v3`, т. е. не выбирал сам) — переключить на `std-auto` один раз; явный выбор другой темы — сохранить.
3. Платформа (React/TS): `src/platform/ui/tokens.ts` — те же токены «Стандартной»; экраны Платформы берут цвета только из токенов.
4. Выбор темы: «Стандартная · Авто / Светлая / Тёмная» — первыми; прежние — ниже, с пометкой «прежние темы».
5. `ai-dev/standards/DESIGN_SYSTEM.md`: раздел «Тема „Стандартная“ — основа дизайн-системы» (палитра, смысл каждого цвета, правила: золото — акцент и главное действие, приглушённые статусы, контраст текста ≥ 4.5:1, где какой цвет); `UI_COMPONENTS.md` — ссылки на токены.
6. Поднять `SW_VERSION` в `sw.js`.

**Вне объёма:** перекраска отдельных экранов вручную (только токены); удаление старых тем; новые компоненты.
