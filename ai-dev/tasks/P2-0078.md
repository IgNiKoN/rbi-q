## 1. Цель

Чтение данных Качества и План/Факта — без проверки прав на каждой строке всей таблицы. Синхронизация читает только изменения.

Что увидит владелец: «откройте приложение на новом телефоне → загрузка Качества заметно быстрее; План/Факт и "Сводка" — за 1–2 с у любой учётки; на графике Beget при входе нет пиков 300 %».

## 3. Объём

1. **Правила чтения (RLS) `quality.*` и `core`/`planfact` без вызова тяжёлой функции на каждой строке.**
   - Права человека считаются один раз на запрос: `(select quality.my_readable_projects(…))` — массив `core_project_id` / `core_company_id`, по которым есть `quality.view` / `construction.view`. Initplan, область по месту — как сейчас.
   - Правило строки — дешёвое сравнение: `core_project_id = any(...)` и т. п.
   - Права записи (сторожа) не трогать, только чтение.
   - Сначала самые тяжёлые таблицы по замеру: `file_registry`, `sk_records`, `rbi_inspection_items`, `rbi_inspection_photos`, `location_nodes`, `construction_*_v2`. Затем остальные таблицы `quality.*` тем же шаблоном. Правило — общая функция, а не копии.
2. **`storage.search` 10 с.** Найти, кто зовёт список файлов (клиент Качества или кэш фото) и зачем. Убрать лишние вызовы или заменить на `file_registry`. Политики `storage.objects` проверить на тот же перебор.
3. **Синхронизация Качества — только изменения.**
   - 11 таблиц, которые сейчас читаются целиком, переводятся на `updated_at > последняя метка − 15 мин`, как остальные.
   - `sk_records` — так же, с постраничной загрузкой.
   - `file_registry` — одним запросом по всем проектам с меткой, а не страницами на каждый проект.
4. **План/Факт:**
   - `pf_my_permissions` по всем проектам — одним вызовом (новая RPC или пакет). Прежняя функция остаётся для совместимости.
   - Предзагрузка всех объектов на новом устройстве — не сразу при входе, а после первого экрана и порциями не больше 3 одновременно.
5. Ограничения: публичные контракты RPC не ломать, офлайн (P2-0060/0064) не ломать, права «до = после».

## 3а. Reuse

EXTEND: правила и функции прав 052/053 (`core.can_at`, `quality.can`) остаются источником истины. Новая функция только собирает из них список проектов один раз на запрос. Своих справочников нет.
