## 2. Подтверждённое исходное состояние (read-only разбор 25.10.2026, не проверено в браузере)

- Подвкладки План/Факта = `nav` манифеста (`js/modules/planfact/planfact.manifest.js:20-34`) → `syncPlatformNav()` (`src/modules/planfact/index.ts:112-127`, фильтр `requiresAccess`) → `window.RBI.platformNav` → `AppModeManager.renderBottomNav()` (`js/modules/settings/features/app-mode-utils.js:719-733, 851-853`) → `shellDesktop.fillNav2(html,'platform')` (`js/core/app-shell.desktop.js:54-90`); на ≥ 1280 нижняя панель скрыта, показывается `#app-nav2` (`css/app-shell.desktop.css:296-304`).
- Вероятная причина (гипотеза, **подтвердить на этапе 1**): пустой список после фильтра доступа (доступ ещё не пришёл / `onAccess` не перерисовал меню) → ветка «почта/Качество», где остаётся только «Настройки», а `fillNav2` её убирает → пустая колонка. На телефоне видна хотя бы «Настройки».
- «История» на ПК: `analytics.desktop.render.js` (`DESKTOP_MIN=1280`, `paintHistoryDesktop` `:1054-1187`) → `history.desktop.content.js` `paintDeskChecks` (`:482-528`): лента объектов + одна плоская таблица (Место / Дата / Вид работ / Инспектор / УрК), галочки `.hist-checkbox`, «Загрузить ещё». Групп Подрядчик → Вид работ нет; действия (выбрать все, удалить, CSV, печать) — общий ряд `#hist-checks-actions-row`.
- Телефон: `history.render.js` — Объект → Подрядчик → Вид работ (аккордеоны, средний УрК, счётчики, ленивая дорисовка) — **не трогать**.
