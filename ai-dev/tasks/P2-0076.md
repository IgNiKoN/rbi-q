## 1. Цель

Владелец открывает «Качество → Внешний СК», загружает Excel. Программа узнаёт фирмы, категории и места, которые уже сопоставлены; новые показывает списком «Разобрать» с подсказкой похожих записей «Компании». После разбора аналитика просрочек считает по подрядчику, виду работ и месту «Компании» — опечатки и разные написания одной фирмы больше не дробят подрядчика. Уже загруженные замечания привязаны разом (по отчёту, после «да» владельца).

**Тест владельца:** откройте «Внешний СК», загрузите выгрузку с фирмой, записанной двумя разными способами, → в «Разобрать» сопоставьте обе с одним контрагентом → в Аналитике это один подрядчик; загрузите тот же файл ещё раз — «Разобрать» пуст.

Повтор — 0 изменений.
3. **Загрузка Excel:** после разбора файла — шаг сопоставления: известное подставляется само; новое — в «Разобрать» с 3 похожими записями «Компании» и выбором; «Создать контрагента» — только при праве в «Компании». Ничего не создаётся в ядре само. Место — до **этажа**; не узнали этаж — остаётся объект / секция.
4. **«Разобрать»:** список в «Внешний СК» (счётчик на подвкладке) — выбрать запись ядра для текста; выбор применяется ко всем замечаниям с этим текстом в проекте; «Отменить».
5. **Аналитика:** группировка и фильтры по id ядра (подрядчик, вид работ, место); у несопоставленных — подпись «не разобрано». Правила «открыто / просрочено» (`sk.issue-rules.js`) не меняются.
