**Статус:** DRAFT (27.10.2026; идея и макет согласованы владельцем; READY — после уточнения вопросов §8 Архитектором с владельцем)

**Источник:** решение владельца 27.10.2026; разбор и формулы — `ai-dev/specs/2026-10-27-quality-month-dynamics.md`; макет — `ai-dev/specs/quality-month-mockup/index.html` (экран), `report.html` (образец отчёта)

## Решения владельца (27.10.2026)

1. «Экран Качества делаем как на макете, включая отчёт, только не делаем отдельную подвкладку — делаем внутри Сводки, например переключатель / кнопку „Динамика за месяц“».
2. Проверка в Качестве — выборочный аудит: сравнение месяц к месяцу честное к объёму выборки (нормировка на 100 проверенных пунктов, пометка «мало данных» при N < 7, разброс ±E), формулы — существующие (`js/shared/math.utils.js`).
3. Это решение снимает для данного экрана правило «экраны Качества не трогать» (память «Качество — образец»): меняется только Аналитика › Сводка, остальные экраны Качества — нет.

## 1. Цель

Руководитель открывает «Аналитика › Сводка», нажимает «Динамика за месяц», выбирает месяц и видит: стало лучше или хуже по сравнению с прошлым месяцем (с учётом объёма выборки), какие дефекты типовые и у кого, что держится несколько месяцев; одной кнопкой получает отчёт за месяц (PDF / PowerPoint).

## 2. Исходное состояние (по разбору, NOT VERIFIED Исполнителем)

- Аналитика Качества: подвкладки Подрядчики · Сводка · История · ПК СК · График (`js/modules/quality/features/analytics/*`); выгрузка в PowerPoint есть (`analytics.pptx-export.js`, `reports.pptx-export.js`).
- Формулы в `js/shared/math.utils.js` (УрК базовый / итоговый, B1/B2/B3, ±E, ступени достоверности, зоны, ИКО); сравнение «с прошлым» сейчас — скользящее окно, не календарный месяц; рейтинг подрядчика — последние 15 проверок.
- Расхождения, найденные при разборе: «открыто» в стройконтроле определено по-разному (`sk.desktop.content.js:89–95` и `analytics.render.js:2905`); «просрочка» в двух местах — по-разному; возможная ошибка: невыполненные пункты B1 попадают в B2 (`reports.actions.js:6044–6047`).

## 3. Объём (черновик)

1. Кнопка «Динамика за месяц» в Сводке (переключатель вида Сводки), выбор месяца, общие фильтры Аналитики.
2. Блоки по макету: объём выборки и надёжность; плитки «этот / прошлый / изменение» с ±E; тренд 12 месяцев; зоны; подрядчики; дефекты (на 100 пунктов, топ-10, тепловая карта, повторы 2+ месяца, причины); объекты (ИКО за 3 месяца); выводы. Стройконтроль — после решения §8.1.
3. Расчёт — одна функция «месяц» поверх существующих формул (без копий формул), с тестами на ручных числах.
4. Отчёт за месяц: PDF и PowerPoint по образцу `report.html`.
5. Адаптив по диапазонам (телефон < 600, планшет 600–1023, ПК ≥ 1024, ≥ 1600 — по центру), светлая и тёмная темы.
