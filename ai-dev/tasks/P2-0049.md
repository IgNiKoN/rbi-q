## Решения владельца (28.10.2026, кнопками)

6. **Ошибка «B1 → B2» в отчёте для совещаний — исправить в этом блоке.** Подтверждено Архитектором по коду: `reports.actions.js` ~6040–6050 — `kind = isB3 ? 'B3' : 'B2'`, пункты веса 1 попадают в B2; в других отчётах B1 из топа дефектов исключён (`reports.actions.js:2601`, `5043`). Сделать так же: B1 в списке дефектов совещания не показывать как B2 (исключить, как в остальных отчётах); счётчики B1/B2/B3 не меняются.

## Решения владельца по ходу работы (28.10.2026, после показа этапа 2)

## 1. Цель

Руководитель открывает «Аналитика › Сводка», нажимает «Динамика за месяц», выбирает месяц и видит: стало лучше или хуже по сравнению с прошлым месяцем (с учётом объёма выборки), какие дефекты типовые и у кого, что держится несколько месяцев; одной кнопкой получает отчёт за месяц (PDF / PowerPoint).

## 6. Критерии приёмки

1. Откройте «Качество → Аналитика → Сводка» → «Динамика за месяц», выберите месяц — видны плитки «этот / прошлый / изменение» с разбросом; при < 7 проверок — «мало данных», без стрелки.
2. Число проверок месяца совпадает с «Историей» за тот же месяц и фильтры.
3. Обычная Сводка без изменений; переключение туда-обратно не теряет фильтры.
4. Одно и то же замечание стройконтроля считается открытым / просроченным одинаково во всех местах Аналитики; ИДЗ на экране Стройконтроля прежний.
5. В отчёте для совещаний нет B1 под видом B2.
6. PDF и PowerPoint за месяц открываются, числа = экрану.
7. Телефон 375 и ПК 1280 / 1920, светлая и тёмная тема — без горизонтальной прокрутки и наложений.
8. `npm run test:unit` PASS, `tsc` 0, сборка без ошибок.

## 8. Риски

- Данных за месяц мало → почти всё «мало данных»: это честный результат, экран должен выглядеть понятно (подсказка «нужно не меньше 7 проверок»).
- Пункт чек-листа менялся между месяцами (версия не хранится) → «тот же пункт» в повторах может значить разное: показывать повторы по id пункта, в ТД.
- Рейтинг инженеров ПК СК после перевода на общее «открыто» покажет больше открытых (ждущие проверки теперь открыты) — ожидаемо, указать в CHANGELOG.
