## 1. Цель

Прораб или РП открывает «План/Факт → Факт → Шахматка» (на телефоне или ПК) и сразу видит, что сделано на каждом этаже. Нажимает на ячейку, видит позиции этого места и вносит факт в два касания (кнопка 25/50/75/100 % → «Внести»). Ячейка сразу перекрашивается.

## 2. Подтверждённое исходное состояние (`main` `9267bf1`)

- **Факт (P2-0007):**
  - `src/modules/planfact/fact/FactTab.ts` — ввод по позиции: объём, дата, бригада, люди, чел.-ч, примечание; переключатель «Ввод / На подтверждение».
  - `FloorClose.ts` — «закрыть этаж/секцию»: остаток или X % от плана, пачкой.
  - `FactPending.ts` — перебор допуска уходит РП на подтверждение.
  - `FactHistory.ts` — история.
  - `BrigadesTab.ts` — бригады.
- **Данные:** `fact.service.ts` → `positions(projectId, locationId|null)` (RPC 009). На каждую позицию приходят: `location_id`, `location_path`, `location_type`, `work_type_id`, `work_name`, `unit_code`, `plan_qty`, `fact_qty`, `pending_qty`, `pending_count`, `last_rejected_note`. Права проверяет сервер.
- **Места (006):** `node_type` ∈ building / section / floor / apartment / other. Генератор корпуса строит «корпус → секции → этажи → квартиры». Дерево мест отдаёт сервис ядра `src/platform/core/` (P2-0015).
- **Демо «Спутник»:** позиции на уровне корпуса, этажей в ВОР нет. Шахматка покажет подсказку «объёмы не разнесены по этажам». Для проверки нужен синтетический объект с этажами.
- **Дизайн-система** `src/platform/ui/`: `KpiTile`, `ProgressBar`, `StatusBadge`, `Legend`, токены графиков (P2-0010). Компонента шахматки и окна быстрого ввода нет.
- **Не подтверждено:** время расчёта шахматки на 5 000+ позиций в браузере. Проверяется на этапе 1.

## 3. Объём реализации

1. **Расчёт шахматки** — чистая функция `chessboard.ts`, без сервера.
   - **Вход:** позиции (`positions(project, null)`) и дерево мест из ядра.
   - **Привязка к ячейке:** позиция квартиры поднимается до её этажа, этажа — остаётся на нём. Позиции выше этажа (корпус, секция, other) в ячейку не попадают, а считаются отдельно: «не разнесено по этажам: N».
   - **Значение ячейки — один вид работ:**
     - одна ЕИ — `Σ факт / Σ план` по объёму;
     - несколько ЕИ у вида работ — «закрыто X из Y позиций» (ЕИ не складывать, §9).
   - **Значение ячейки — «все виды»:** «закрыто позиций X из Y». Позиция закрыта, если `fact_qty ≥ plan_qty`.
   - **Цвет ячейки:** серый — не начато, жёлтый — в работе, зелёный — сделано. Отдельные значки: «ждёт подтверждения» (`pending_count > 0`) и «отклонено» (`last_rejected_note`).
   - Цвета — только токены дизайн-системы (светлая и тёмная тема), не одним цветом: число и значок дублируют смысл.
2. **Вид «Этажи × секции».**
   - Выбор корпуса и вида работ (или «все виды»).
   - Строки — этажи сверху вниз, столбцы — секции.
   - Тултип / нажатие: план, факт, остаток, позиций, «ждёт подтверждения».
   - Подсветка выбранной строки и столбца. Легенда.
3. **Вид «Этажи/квартиры × виды работ».**
   - Строки — этажи, с раскрытием до квартир. Столбцы — виды работ.
   - Первая колонка закреплена; прокрутка вбок — внутри таблицы, страница вбок не прокручивается.
   - Переключатель видов — подвкладкой или сегментом в «Шахматке». Выбор запоминается на устройстве.
4. **Быстрый факт из ячейки.**
   - Нажали на ячейку — открывается список позиций места: на телефоне шторкой, на ПК боковой панелью.
   - **Окно ввода по позиции (по образцу Sarex):**
     - поле объёма с «−/+»;
     - плитки 25/50/75/100 % плана с числами в ЕИ позиции;
     - «Внесено / Осталось»;
     - дата и бригада (последняя бригада подставляется, как сейчас), примечание;
     - «История (N)» открывает имеющуюся `FactHistory`.
   - Отправка — **тот же** сервис и правила, что в `FactTab`: перебор допуска уходит на подтверждение. Ячейка перерисовывается после ответа сервера.
   - Из ячейки этажа — кнопка «Закрыть этаж», через имеющийся `FloorClose`.
5. **Самопроверка, документы, версия.** `sw.js` (SW_VERSION), «История обновлений», APP_GUIDE (как читать шахматку, правило ЕИ), FILE_MAP, CHANGELOG.

## 8. Риски и зависимости

- **Большие объекты:** если позиций > 20 000, загрузка `positions(project, null)` может быть медленной. Мера: замер на этапе 1. Если медленно — `BLOCKED` и вопрос Архитектору о серверной сводке (отдельный блок, CRITICAL).
