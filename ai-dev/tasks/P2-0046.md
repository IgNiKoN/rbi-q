## 1. Цель

Утверждённые образцы, из которых собираются все новые экраны платформы (первыми — экраны ядра P2-0047 «Подразделение → Проект → Объекты → места»), и одна страница-витрина, где владелец видит каждый образец на телефоне, планшете и ПК, в светлой и тёмной теме.

## 2. Подтверждённое исходное состояние

- Токены и темы есть (`--p2-*`, `rbi-light-v3`/`rbi-dark-v3`, опубликованная дизайн-система); компоненты `src/platform/ui/` (KpiTile, ProgressBar, StatusBadge, графики, RegistryTable, SideCard) и шапка раздела `src/modules/planfact/PageHead.ts` (P2-0041).
- Оболочка (`css/app-shell.desktop.css`): < 768 — нижняя панель; 768–1279 — узкая панель + нижняя панель; ≥ 1280 — панель + второй уровень + верхняя строка. Оболочка общая со старым Качеством (`js/`).
- План/Факт сейчас: 8 значков, подпись только у открытого; три уровня вкладок; выбор объекта на каждом экране; заголовки и вкладки ПРОПИСНЫМИ; на 375 px подвкладка «Журнал» не видна; пункт без права виден с текстом «нет права» (стенд, 27.10.2026).

## 3. Объём

1. Правила раскладки и удобства — раздел «Экраны и размеры» в `standards/DESIGN_SYSTEM.md` по `specs/2026-10-27-screens-and-layouts.md` п. 1, 4, 5.
2. Навигация платформенных модулей по размерам: телефон — нижняя панель ≤ 5 пунктов с подписями (5-й «Ещё»); планшет и ПК — вкладки раздела с подписями; пункты без права и без лицензии не показываются; выбор проекта — один в шапке.
3. Компоненты-образцы в `src/platform/ui/`: шапка страницы (заголовок · крошки · одно главное действие), вкладки (2 уровня, спокойная активная), пустое состояние / нет прав / ошибка / нет связи, список-адаптив (таблица ↔ карточки), лист ввода снизу (телефон) / боковая панель (ПК), закреплённая кнопка действия (safe area, клавиатура), статус-метка (цвет + слово).
4. Страница-витрина `#/platform/patterns` (видна администратору платформы) — восемь образцов на подставных данных.
5. Автопроверка «нет горизонтальной прокрутки страницы» на шести размерах + снимки экранов в отчёт.
