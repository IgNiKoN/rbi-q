## Что сделано

- `css/style.css`: блоки `html[data-theme="std-light"]` / `std-dark` — все токены тем v3 (проверяется тестом) + `--card-bg-2`, `--sel-bg`, `--accent-text`, `--btn-primary-text`, `--color-violet`, `--ok-text`, `--warn-text`, `--bad-text`. Правила компонентов: v2/v3 получают их явными селекторами по имени темы → скриптом (postcss) к каждому из 79 правил `rbi-*-v3` добавлена пара `std-*` (блоки токенов v3 исключены). Отличия std — небольшой блок только на токенах: золотое главное действие с тёмным текстом (`bg-indigo-*`, `bg-brand`), красные подложки и статус-текст из палитры, фиолетовый. В правилах v3 кнопок `color: #fff` → `var(--btn-primary-text, #fff)` (для v3 без изменений). Класс `dark` на `<html>` для std-dark ставится как у прежних тёмных (Tailwind `dark:`).
- `css/brand/rbi.css`: шрифт IBM Plex (как у v3) и для std — шрифт не менялся, задача про цвета.
- `js/shared/theme.utils.js` (новый, в `<head>` до CSS/Tailwind и в precache `sw.js`): `RBI_THEME` — список, `resolve`, `migrate`, `apply`, ранняя установка из `rbi_theme_preference`. `settings.service.js`, `settings.actions.js` (перенос при загрузке без смены `settingsUpdatedAt`; экспорт `rbiMigrateTheme`), `settings.render.js` (группы «Стандартная» / «Прежние темы», применение через `RBI_THEME`, реакция «Авто» на смену схемы), `sync-engine.core.js` (облачная `rbi-auto-v3` старше отметки → `std-auto`), локали ru/en/sr-Latn/ka.
- `src/platform/ui/tokens.ts`: `STD_THEME`, `std-dark` в `P2_DARK_THEMES`, статусы и серии `--p2-*` из палитры.
