## Пользовательский сценарий
1. Обновить страницу дважды (SW 18.85.0). Владелец (админ платформы) по почте → «Настройки → Админ платформы»: у каждой компании 5 выключателей.
2. Демо-компания → выключить «База знаний» и «ИИ-помощник». Сотрудник Демо по почте (обновить страницу): в Качестве нет вкладки «База знаний»; в «Настройки → ИИ» — «ИИ-помощник выключен для вашей компании», переключатель недоступен. Включить обратно — всё вернулось.
3. Сотрудник RBI по почте: Качество → «База знаний» — документы на месте; ИИ отвечает (как до блока).
