# P2-0060 — план выкладки

**Разрешения на выкладку пока нет** — выкладка только по прямому разрешению владельца после приёмки (этап 1 — зона CRITICAL «вход»: Архитектор смотрит diff этапа 1 при приёмке).

## 1. Что выкладывается

| Часть | Что | Как |
|---|---|---|
| Сервер | **ничего** — функции сервера, права, миграции, nginx не менялись | — |
| Приложение | ветка `task/P2-0060-offline-any-module` → `main` → `git pull --ff-only` в `/var/www/rbi-quality`; бандлы `js/dist/{platform,planfact,company}`, оболочка `js/core/app-shell.js`, Настройки `js/modules/settings/settings.render.js`, автокэш `js/services/storage/*`, `js/services/sync/sync-core.state.js`, `sync-engine.core.js`, манифесты (поле `offline`), обёртки `js/modules/{planfact,company}/index.js`; новая опись версии в `sw.js` (P2-0066) | приложение переключится само при следующем запуске или кнопкой «Перезапустить сейчас» |
| Служебное | `tests/offline/{menu,view,files,device}.mjs`, `ai-dev/reports/P2-0060/` | nginx `rbi-router` не отдаёт (`tests`, `ai-dev` уже в правиле) |

## 2. Что увидят люди

- Меню при запуске — сразу (из памяти), даже если сервер завис; старого меню Качества больше нет.
- План/Факт и «Компания» без сети — просмотр с пометкой «Без сети · данные на …»; через 8–10 с после запуска с интернетом телефон сам скачивает «мои проекты» (раз в сутки).
- «Настройки → Данные на устройстве» — новый блок «Офлайн по модулям»; «Авто-кэш» и «Скачать …» переехали из «Хранилища» в него.
- Фото заранее — по роли: инженер / подрядчик — свои объекты за 30 дней + открытые замечания; руководитель — не качается (уже скачанное **не удаляется** само — только «Очистить скачанное»).
- Неотправленные записи на телефоне не трогаются ни очисткой, ни правилом; уходят как раньше.

## 3. Шаги

1. Свежий `main` в ветку (если ушёл вперёд); `npm run build:platform && npm run build:planfact && npm run build:company` (последней — `build:version`), `npm run test:unit`, `npx tsc --noEmit`, `node tests/offline/run.mjs` (все сценарии).
2. Слияние в `main` (fast-forward), push в `IgNiKoN/rbi-q` — по разрешению владельца.
3. Сервер (панель Beget → терминал VPS): `cd /var/www/rbi-quality && git rev-parse HEAD` (запомнить) → `git pull --ff-only` → `git rev-parse HEAD` = коммит `main`.
4. Проверка без входа: `node scripts/check-release.mjs` — каждый файл описи на сайте совпадает с отпечатком.

**Откат:** на сервере `cd /var/www/rbi-quality && git reset --hard <запомненный HEAD>`; устройства переключатся на прежнюю версию тем же путём (P2-0066). Копия для просмотра (`platform2_offline_copy`) прежней версией не читается и не мешает.

## 4. Полевой тест владельца (телефон, 15 минут)

1. Войти с интернетом, открыть План/Факт → Сводку; подождать 15 секунд (заранее скачаются ВОР, Факт, шахматка).
2. «Настройки → Данные на устройстве» — блок «Офлайн по модулям»: модули, размеры, «Держать без сети», «Фото и PDF заранее».
3. Включить авиарежим, закрыть и открыть приложение: меню — сразу; План/Факт → ВОР, Факт → любой этаж, шахматка — видны с пометкой «данные на …», «Внести факт» неактивна.
4. Записать осмотр в Качестве без сети, «Очистить скачанное» у Качества — осмотр и его фото на месте; выйти на связь — осмотр ушёл.
5. **Замер места на телефоне (ТД 225):** до и после — «На телефоне … МБ» в шапке блока у инженера и у руководителя; прислать снимок.

**Не проверялось на настоящих iPhone / Android** (стенд — Chromium, подставной сервер).
