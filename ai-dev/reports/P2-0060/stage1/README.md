# P2-0060 этап 1 — права и меню сразу из памяти: замер до / после

Стенд `npm run test:offline` (подставной сервер, боевой не используется), погода `hang` — сервер принимает запрос и молчит.
Сценарии `tests/offline/menu.mjs`: покадровая запись каждые 100 мс с первой строки страницы.

Причины (найдены на стенде):
1. Пока вход платформы не ответил, оболочка считала «никто не вошёл» и рисовала меню старого Качества.
2. `loadEmail` ждал `pf_my_platform` / `pf_my_profile` без ограничения; копия прав бралась только при ошибке связи.
3. Подвкладки План/Факта строились только по ответу сервера раздела (`pf_my_company_access`), раздел висел на «Загрузка…».
4. Мост Качества ждал `my_access` и список объектов без ограничения — Качество и Стройконтроль пропадали из меню.

Найдено и исправлено по ходу (регрессия стенда P2-0058/0059):
- `cold375/1440`: фоновая проверка объектов без связи получала пустой список (сервис ядра на ошибке отдаёт `[]`) и затирала копию → синхронизация выключалась. Теперь объекты из ядра — только после подтверждения сервером.
- `w-hang`: при «без связи» разделы по событию `rbi:platform-access` заново спрашивали молчащий сервер, запросы висели и занимали все 6 соединений браузера → синхронизация не доходила до сервера и после того, как он ожил. Теперь проверка прав не дублирует висящий запрос, а событие для перезапросов — только при смене прав или когда сервер снова ответил (признак связи — отдельное `rbi:platform-net`). `w-hang`: 6,6 мин, как до.
