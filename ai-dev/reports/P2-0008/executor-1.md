## Пользовательский сценарий

1. Роль РП/ПТО/экономист/руководство, проект с подтверждённым ВОР, договорной КП (выбрана в «КС-2»), принятым фактом.
2. «План/Факт → Сводка» → «Даты проекта» (РП/ПТО) → «Открыть» → виды работ → «Позиции по местам» → «Сделано ↔ КС-2» → «Скачать Excel».
3. Ожидаемо: % готовности по деньгам КП, темп, прогноз, светофор; объёмы в своих ЕИ; разрыв КС-2; файл из трёх листов. Войти прорабом — рублей нет.
