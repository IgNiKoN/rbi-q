## Решения Исполнителя (на приёмку)

1. **`core.has_grant` + `core.can_at`** вместо одной `can_at`: `planfact.has_permission` проверяет включённость только План/Факта, а не модуля действия (`pf_my_permissions` отдаёт и ключи Качества при выключенном Качестве — тест 014). Чтобы не менять поведение, назначения — `has_grant`, модуль — `can_at`.
2. **`row_allowed` принимает список действий** (любое из) — правило правки строки: какое именно действие, решает сторож.
3. **Тест 047:** выборка `area_scoped` сужена до `planfact.*` — список План/Факта тот же; в каталоге по плану появились действия СК с `area_scoped`. Других изменений ожиданий План/Факта нет.
4. **Сторож только для запроса клиента** (роль `authenticated` / `anon`): тесты 048/049 пишут замечания «как сервер» — иначе отказ; RLS для этих ролей тоже не действует.
5. **`core.my_grants`** — одна функция участия для телефона обоих модулей; вкладка «Кто что может» — модули с действиями `area_scoped` (Качество появится после блока 4б2), группа «Прежний доступ» не показывается.
