## 2. Совместимость

- Новое приложение работает с нынешним сервером без изменений (те же `pf_my_platform`, `pf_my_profile`, `my_access`, `pf_company_projects`).
- На устройстве появляются ключи `platform2_device_access_<пользователь>` (копия ответа прав) и `platform2_quality_access_<компания>:<пользователь>` (копия прав Качества и объектов). «Выйти» стирает первую; старый код их не читает.
- Первый запуск после обновления — с интернетом (так и будет: обновление приходит по сети) → копия прав сохраняется. Кто после обновления сразу ушёл без сети, не открыв приложение с интернетом, без копии прав увидит меню как раньше, но база компании уже не переключится.

## 4. Проверка владельцем (телефон)

1. Войти с интернетом, открыть Качество. Закрыть приложение.
2. Включить авиарежим, открыть снова: меню и осмотры на месте, плашка «Нет связи — данные сохраняются на телефоне», в шапке значок с «0».
3. Записать осмотр → значок «1». Нажать на значок → «Данные на устройстве», сверху «Нет связи · не отправлено: 1».
4. Открыть «План/Факт» → «Нужен интернет».
5. Выключить авиарежим → в течение минуты значок исчезает, осмотр — в журнале на компьютере.

**Не проверялось на настоящих iPhone / Android** (стенд — Chromium в режиме телефона): сценарий выше — для владельца.
