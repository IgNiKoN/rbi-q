# P2-0073 — план выкладки

**Что выкладывается:** только сайт (файлы приложения: `js/dist/platform`, `js/dist/company`, `js/dist/planfact`, `sw.js`). **Миграций нет**, база на сервере не меняется, версия базы на телефоне (IndexedDB) не менялась.

## 1. До выкладки
- Владелец: «Архитектор. принято P2-0073» → влить ветку `task/P2-0073-device-screen-fast` в `main` (по разрешению владельца), `git push` (по разрешению).
- Если в `main` уже влита P2-0072 — при влитии пересобрать бандлы и опись версии: `npx vite build --config vite.platform.config.ts`, `… vite.company.config.ts`, `… vite.planfact.config.ts`, затем `npm run build:version` (конфликты в `js/dist/*` и `sw.js` не правятся руками — пересборка). Номера техдолга 384–385 — после 383 у P2-0072.

## 2. Выкладка (владелец, терминал Beget)
- `cd /var/www/rbi-quality && git pull --ff-only`.

## 3. Откат
- `git reset --hard <прежний коммит main>` в `/var/www/rbi-quality` — данных не трогает (миграций нет).

## 4. Проверка после выкладки (владелец, 5 минут)
1. На телефоне: «Перезапустить сейчас» в «Настройки → Помощь и о программе» (или закрыть и открыть приложение).
2. «Настройки → Данные на устройстве»: карточки «Отправка» и «Офлайн по модулям» видны сразу; на месте цифр на секунду-две может быть «считаем…» или «· на ЧЧ:ММ» — потом цифры появляются сами. Переключатель «Держать без сети» нажимается сразу.
3. Значок «не отправлено: N» в шапке (если есть) = число в карточке «Отправка».
4. ПК: «Настройки → Сотрудники и доступ → Кто что может» → нажать на роль у человека → открылись «Роли и права» с этой ролью; «Назад» → нажать на имя → открылись «Сотрудники» с его назначениями.

**Не проверено до выкладки:** живой телефон владельца (замер — на стенде с процессором ×6 и медленной / занятой связью).
