## Пользовательский сценарий для Тестера

1. Вход почтой (демо-прораб) → «План/Факт → Факт» → «Шахматка» → объект с этажами (синтетика генератором корпуса) — сетка, легенда; «Спутник» — подсказка «не разнесены по этажам».
2. «Вид работ» → один вид — % по объёму; «Все виды» — «X/Y поз.». «Этажи × виды работ» → нажать этаж → квартиры.
3. Нажать ячейку → «Внести факт» → «до 50 %» → «Внести» — ячейка перекрасилась; ввести больше допуска — значок «ждёт подтверждения», у демо-РП в «Вводе → На подтверждение».
4. Заказчик (только просмотр) — нет «Внести факт» и «Закрыть этаж».
5. Телефон 375 px и ПК, светлая и тёмная тема — страница не прокручивается вбок.
