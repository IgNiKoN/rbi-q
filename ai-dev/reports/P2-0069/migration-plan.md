**30.10.2026, Исполнитель.** Основа — светофор (`inventory.html`): 105 таблиц, **145 красных клеток** (153 нарушения в потолке `reference/schema-debt.json`). Каждое красное отнесено к шагу — полный список «таблица → правило → шаг» в [`plan-map.md`](plan-map.md) (создаёт `plan-map.mjs`; красное без шага — ошибка генератора). Сверка с боевой 30.10: в `core`, `planfact`, `quality` боевая = миграции, план опирается на настоящую схему.

## Как переезжаем

- **Чинить там, где блок всё равно трогает таблицу** (MODULES §9), без отдельного «большого рефакторинга». Сторож не даёт красному расти; блок, починивший таблицу, снижает потолок (`--update-debt`).
- **Качество, Стройконтроль, СК — только «поле рядом»** (решение владельца 30.10.2026): добавить правильное поле (`core_created_by`, `core_location_id`, `core_counterparty_id`, `deleted_at`, `created_at`), заполнить по сопоставлению, писать в оба, старое снять уборкой (мост с датой снятия — пункт в `TECH_DEBT.md`, спека п. 14). **Переименований в таблицах Качества нет.**
- **`core`, `planfact`** — во всех шагах только добавление колонок и внешних ключей: переименований план не требует, проверка «код читает только через RPC» не нужна. Если блок захочет переименовать — сначала эта проверка по коду.
- Миграции — добавляющие (ADR-061), каждая с откатом; на боевую — только по разрешению владельца.

## Вопросы Архитектору

1. **Ключ Качества** (41 красное): `id text`, созданный на устройстве, устойчив и не дублируется — это суть §9 п. 1. Оставить классом исключения «id с устройства (RBI)» или добавлять `uuid` рядом при переносе модуля?
2. **Аналитика внешнего СК** (`sk_*`, 21 красное): модуль отомрёт (MODULES 5.5). Класс «переходный модуль» (жёлтый) или минимум — автор и удаление при следующем касании?
3. **Валюта:** в каждой строке (`currency` в строке сметы, КС-2) или у родителя (проект / смета / прайс) с правилом «строка — в валюте родителя»? Стандарт сейчас требует в строке; для дочерних строк логичнее родитель.
4. **`created_by` у каталогов ядра и у `core.companies`:** компании создаёт администратор платформы — оставить требование (шаг Я1) или класс «создаёт платформа»?


## Ответы (приёмка 30.10.2026, решения владельца — `acceptance-record.md`)

1. Ключ Качества — **по стандарту, постепенно**: новые записи → `uuid` с телефона; старым — `uuid` рядом, связи по нему; старый номер — уборкой. Шаги **К1, К6 → блок 4в** «Номера Качества по стандарту».
2. `sk_*` — модуль **постоянный**: связи по id ядра через сопоставление при импорте. Шаг **СК → блок 4г** «Внешний СК по номерам».
3. Валюта — **одна на смету**: ПФ3 — `currency` у проекта, сметы, прайса, договора; строки без своего поля.
4. `core.companies` — `created_by` **добавить** (Я1).
