## Что сделано

1. **План/Факт на ПК, пустая вторая колонка.** Причина подтверждена на стенде и уточнена у владельца (кнопки: вход «демо», видно «пустая колонка меню»): без входа сервер не подтверждает доступ → все пункты манифеста (`requiresAccess`) отфильтровываются → `platformNav` пуст → оболочка рисует меню режима (пустую колонку или меню Качества). С входом по почте (ПТО) меню было и есть. Решение владельца (кнопка «Все разделы + „войдите“»): в демо — все разделы; «ВОР» — разбор файла, остальные — подсказка «Войдите…» и «Войти». Код: `src/modules/planfact/nav-items.ts` (`visibleNavItems`), `index.ts` (`onDemo`), `PlanfactApp.ts` (проп `onDemo`), пересборка `js/dist/planfact/`.
2. **«История» ПК → «Проверки» — таблица с группами** (решение владельца «Таблица + группы»): «Все объекты» — Объект → Подрядчик → Вид работ → строки; выбран объект — Подрядчик → Вид работ. У группы: число проверок, средний УрК (цвет как на телефоне), раскрыть/свернуть, состояние сохраняется при сортировке/фильтре/перерисовке. Сортировка по колонке — внутри вида работ. Общий модуль `history/history.group.js` (имена подрядчика/вида работ, средний УрК и цвет, раскладка) — телефон (`history.render.js`) теперь берёт эти функции из него же.
3. **Галочка группы** — отмечает все проверки группы (и вложенные группы).
4. **Попутно исправлено (без них критерий 3 не выполнялся):** `getSelectedHistoryIds` — без повторов (на ПК «Выбрать все» ставил галочку и в скрытом телефонном списке: 600 id на 300 проверок → печать каждого акта дважды, «Удалить 600 шт»); после удаления вызывается `window.renderHistoryTab` (раньше перерисовывался только телефонный список, таблица ПК оставалась старой). Файл `history.actions.js` в разделе 4 карточки не назван — отступление, 2 точечные правки.
