1. Свежий `main` в ветку (если ушёл вперёд); пересборка `npm run build:platform && npm run build:planfact && npm run build:company`, `npx tsc --noEmit`, `npm run test:unit`, стенд `node tests/offline/run.mjs pf-offline pf-drop pf-batch`.
2. **Сервер:** снимок базы (панель Beget) → в SQL Editor выполнить `051_fact_client_id_up.sql` → проверка: `select to_regprocedure('public.pf_fact_submit(uuid,jsonb)') is not null, (select relrowsecurity from pg_class where oid = 'planfact.fact_submissions'::regclass);` → `true, true`.
3. Слияние в `main` (fast-forward), push в `IgNiKoN/rbi-q` — по разрешению владельца.
4. Сайт: `cd /var/www/rbi-quality && git rev-parse HEAD` (запомнить) → `git pull --ff-only` → `git rev-parse HEAD` = коммит `main`; `node scripts/check-release.mjs`.

**Откат (обратный порядок):** сначала сайт — `git reset --hard <запомненный HEAD>` (старая версия вносит факт прежними `pf_fact_add*`); затем, если нужно, `051_fact_client_id_down.sql` (снимает функцию и таблицу принятых номеров; записи факта остаются). Неотправленный факт на телефонах после отката приложения остаётся в базе записей устройства и уйдёт после повторной выкладки.

## 4. Полевой тест владельца (телефон, 15 минут)

1. С интернетом открыть План/Факт → Факт → свой этаж (заодно скачается копия).
2. Включить авиарежим: внести факт по работе и «Закрыть этаж целиком» — «Сохранено на телефоне», у работы «Не отправлено», в шапке — «не отправлено: 2».
3. Журнал — блок «С этого телефона ещё не ушло: 2»; шахматка — значок ↑ в ячейке этажа.
4. Выключить авиарежим: через полминуты пометки пропали, факт в журнале со статусом сервера; «Данные на устройстве → Отправка» — «Всё отправлено».
5. Подвал / слабая связь: внести факт, отойти туда, где связь пропадает в момент «Записать», — после возврата связи запись одна (не две).

**Не проверялось на настоящих iPhone / Android** (стенд — Chromium, подставной сервер); одновременная отправка одного номера с двух вкладок на настоящем сервере — только логикой (`on conflict` ждёт первую), на PGlite не воспроизводится.
