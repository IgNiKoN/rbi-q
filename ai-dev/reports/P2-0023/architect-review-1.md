## Блокирующие (HIGH) — проверены Архитектором по коду

1. **Автоочистка удаляет навсегда неотправленные записи со статусом `blocked`.** `js/services/sync/sync-merge.policy.js:14-19` — `isUnsentLocal` исключает `blocked`; `keepOnPurge` → `js/modules/settings/features/app-mode-utils.js:975-997` удаляет запись и её `local://` фото. До P2-0023 оставалось всё с `source === 'local'`. Сценарий: офлайн-проверка по неназначенному объекту (или вся пачка после временной ошибки RLS, `sync-engine.core.js:2525`) получила `blocked` → смена назначенных объектов → запись стёрта, на сервер не ушла.
   **Нужно:** `keepOnPurge` оставляет любую `source === 'local'` с любым статусом, кроме `synced` (в т.ч. `blocked`); unit-тест.
2. **Одно отсутствующее фото навсегда «паркует» всю проверку.** `sync-engine.core.js:2453-2466` + `sync-retry.policy.js:63-66`, фильтр отправки `sync-engine.core.js:2293`. Ошибка «файла нет» изначально ловила гонку «файл ещё не записан» (комментарий `sync-engine.core.js:575-582`); теперь проверка уходит в `needs_attention` без автоповтора, снимается только ручной правкой; в истории — обычная «локальная» плашка без причины.
   **Нужно:** автоповтор `needs_attention` с той же паузой 2/5/10/30 мин (не чаще, без полной загрузки); после N неудач — понятная плашка «Не отправлено: нет фото пункта …» с действием «Отправить без этого фото» (фото помечается отсутствующим, остальное уходит); unit + стенд.
