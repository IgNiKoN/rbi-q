## Пользовательский сценарий для Тестера

1. Телефон 375: План/Факт → внизу «Сводка · Входящие · ВОР · Факт · Ещё»; «Ещё» → Смета, КС-2, Справочники, Настройки.
2. Сводка → «Требует внимания» → «К КС-2» открывает КС-2 нужного объекта.
3. Факт → Ввод → Корпус → Этаж → нажать работу → окно ввода снизу → внести.
4. Факт → Ждёт РП → «Принять» в строке; «Принять без перебора · N» → «Да».
5. КС-2 → «Новый акт» внизу экрана; «Выбрать» → галочки → «Выгрузить в Excel».
6. ПК: Факт → Ввод — дерево корпусов и этажей слева; Цены → нажать строку → правка.
