## Отступления от карточки

- **Площадь — прежний столбец `core.locations.area`** (`006`), новый не заводился (один источник истины); новый только `rooms` и служебный `import_batch`.
- **`pf_save_place` не расширялась** — площадь и комнаты отдельной `pf_save_place_info`: иначе прежний вызов без новых аргументов стирал бы площадь.
- **Обе `pf_copy_place` пересозданы** — копия переносит комнаты (тело — из `045` / `049`, `down` возвращает их текст побайтно).
- **Названия новых мест — по образцу соседей** (`core.import_pattern`; в карточке — «Этаж 3», «Кв. 45» не по правилам приложения): без этого на стенде получался разнобой «1 этаж … эт. 6». Если образец даёт занятое название — понятный отказ строки.
- Номер помещения без номера в файле — после наибольшего из номеров объекта **и файла** (чтобы не совпасть с номером ниже по файлу).
- Сборка «Компании» — библиотека Excel отдельными файлами `chunks/` (иначе ≈1,4 МБ вошли бы в `company.js` для всех).
- «Глубже 6 уровней» в загрузке недостижимо (максимум 4 уровня) — проверки нет.
