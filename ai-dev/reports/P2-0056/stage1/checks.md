## Отступления от карточки (п. 3.1)
- **Площадь — прежний столбец `core.locations.area`** (`006`, `>= 0`, уже копируется `pf_copy_place`), новый не заводится: один источник истины. Новый только `rooms smallint` (0–20, только у `apartment`) и служебный `import_batch uuid`.
- **`pf_save_place` не расширялась:** площадь и комнаты — отдельная `pf_save_place_info(место, площадь, комнаты)`. Иначе прежний вызов без новых аргументов стирал бы площадь (null = «стереть» или «не менять» — не различить); прежняя функция побайтно та же.
- **Обе `pf_copy_place` пересозданы** (`create or replace`): копия переносит и комнаты (площадь переносила и раньше); остальное тело — как в `045` / `049` (генерация из исходных файлов, `down` возвращает их текст).
- Номер помещения без номера в файле — **после наибольшего** из номеров объекта и номеров этого объекта в файле (чтобы не совпасть с номером ниже по файлу).
- Названия — как в приложении: «Секция N», «эт. N», «кв. N» (не «Этаж», «Кв.»); сопоставление с существующими — по названию, иначе по номеру в конце («2 этаж» = «эт. 2»), у помещения ещё по строительному номеру; только если такое место на уровне одно.
- «Глубже 6 уровней» в загрузке недостижимо (объект → секция → этаж → помещение = 4) — проверка не нужна.

## Доработка этапа 1 (28.10.2026, по стенду этапа 2)
- **Названия новых мест — по образцу соседей:** на стенде этажи «1 этаж», а загрузка создавала «эт. 6» — разнобой. `core.import_pattern` берёт образец у соседей того же вида, затем у мест того же вида под соседями родителя, затем у последнего такого места проекта; применяется только к названиям вида «Секция N», «эт. N», «кв. N» (образец уровня считается один раз). Если образец дал название, которое уже занято (на уровне два места с одним номером), — отказ строки «На этом уровне несколько мест с таким номером — уточните название в файле».
- **Скорость:** поиск по уровню переписан под индексы (`project_id` + родитель; `locations_sibling_uq`); замер 200 / 400 / 800 строк — 108 / 222 / 515 мс; 5000 строк — ≈8,7 с на PGlite (до доработки с образцом названий было 53–215 с).
- Повторно: тест `050` **FAIL 0** (+2 проверки: названия по образцу, два места с одним номером); 8 мутаций ловятся (m8 — без образца названий — FAIL 2; m3 — FAIL 11); `down` побайтно; регрессия = база. md5 up `7ca31efc…` (497 строк), down `b46f06a1…` (197 строк).
