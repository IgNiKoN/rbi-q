## Что сделано

- **Опись версии при сборке** — `scripts/app-version.mjs` (`npm run build:version`, вызывается последним в `build:*`): все файлы приложения по общему с выпуском правилу (`scripts/app-files.mjs`, EXTRACT из `release-rbi-q.mjs`) с отпечатком sha-256 и размером, группы «оболочка / модули» (префиксы допуска P2-0013 — теперь только здесь), номер «дата-отпечаток» (в отпечаток входит и код `sw.js`). Встроена в `sw.js` (участок `<app-version>`); `SW_VERSION = APP_RELEASE.version`, ручных `SW_VERSION`, `APP_VERSION 18.59.0`, `urlsToCache` нет. Без изменений файлов номер и дата не меняются.
- **Сторож** `js/shared/__tests__/app-version.test.js`: опись актуальна; подключения `index.html` и догрузки бандлов `js/dist` в описи и в той же группе; выпуск = опись; номер стабилен / меняется от байта.
- **Установка целиком** (`sw.js` `installVersion`, `fillVersion`): кэш `platform2-v<версия>`; оболочка + допущенные модули; файл с тем же отпечатком — копией из прежней версии (заголовок `x-p2-hash`), остальное — `cache: 'reload'` со сверкой sha-256; любая ошибка → установка не удалась, прежняя версия на месте (причина: нет связи / файл другой версии / мало места). Допуск модулей — в постоянной памяти (`p2-app-meta`), докачка модулей той же версии при допуске, модули без допуска удаляются из всех версий.
- **Отдача из своей версии, вкладка = версия** (`serveApp`, `cleanupVersions`): файлы приложения — только из кэша версии вкладки (по `resultingClientId` при открытии, хранится в `p2-app-meta`), без фоновой перезаписи (ТД 227 закрыт); прежняя версия удаляется, когда закрыта её последняя вкладка; устанавливаемая — не трогается.
- **Переключение:** ранний участок `index.html` — при запуске (одна перезагрузка, защита от петли — раз в минуту на вкладку); `js/shared/pwa-update.utils.js` — при возврате из фона ≥ 30 мин, если «не отправлено: 0», синхронизация не идёт и нет ввода (`RBI.appBusy` + видимые признаки); «Перезапустить сейчас»; другие вкладки не перезагружаются. Правила — чистые функции `js/shared/app-update.policy.js` (+ unit).
- **Строка версии вместо плашки** — `<p2-app-version>` первой в «Настройки → Помощь и о программе» (по макету этапа 4, утверждён владельцем): 4 состояния, «Перезапустить сейчас», «Проверить обновления» (переехала из низа панели); плашка убрана; `RBI_APP_VERSION` / `APP_VERSION` для диагностики и отчёта для разработчика — из описи (было устаревшее 18.59).
- **Стенд «выкладка во время работы»** `tests/offline/release.mjs` (версии A/B с метками в каждом `.js`, выкладка в процессе, сбой файлов, переход с боевой 18.104.1); сервер стенда — `site.root/pick/fail`, отпечаток подменённого стендом `config.service.js` — в описи.
- Тесты кэша приложения перенесены на новую установку (`sw-legacy.test.ts` — настоящие `Response`/`crypto`, файлы с диска; `sw-harness.ts` — область и `registration`); смысл проверок P2-0013 / P2-0032 / P2-0016 / P2-0018 сохранён.

1. Открыть приложение, «Настройки → Помощь и о программе» — вверху «Версия … от … · это последняя версия».
