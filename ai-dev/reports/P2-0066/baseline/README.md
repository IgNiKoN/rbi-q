# P2-0066 этап 1 — стенд «выкладка во время работы»: замер на текущем коде (`main` `4eee56a`, SW 18.104.1)

Команда: `node tests/offline/run.mjs r-size r-deploy r-middeploy r-partial r-tabs r-chunk r-requests --out <папка>` → PASS 8, FAIL 8 (`report.txt`, `release.json`).
Стенд (`tests/offline/release.mjs`): версии A и B собираются из файлов приложения (`isReleaseFile`); в каждый `.js` дописана метка версии, в `index.html` — `self.__HTML`; B — новый `SW_VERSION` и новое имя части `xlsx-reader-*` (как после пересборки). Сервер стенда отдаёт файлы из папки версии (`site.root`), «выкладку в процессе» (`site.pick`) и сбой файлов (`site.fail`). Каждый сценарий начинает с входа и прогрева на A (разделы План/Факт, «Компания», Качество).

| Сценарий | Что делали | Результат на текущем коде |
