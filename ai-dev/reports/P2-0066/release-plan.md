# P2-0066 — план выкладки

**Разрешение владельца (29.10.2026):** «если все тесты пройдут ок — сразу выкладывай в репозиторий и на сервер через git pull в панели управления Beget в Chrome; дополнительно ни о чём можешь не спрашивать в этой задаче».

## 1. Что выкладывается

| Часть | Что | Как |
|---|---|---|
| Сервер | **ничего** — миграций нет, nginx не меняется | — |
| Приложение | ветка `task/P2-0066-clean-update` → `main` → `git pull --ff-only` в `/var/www/rbi-quality`; новый кэш приложения (`sw.js` с описью версии), `js/shared/app-update.policy.js`, строка версии, ранний участок `index.html` | push в `IgNiKoN/rbi-q` |
| Служебное | `scripts/app-version.mjs`, `scripts/app-files.mjs`, `tests/offline/release.mjs`, `ai-dev/reports/P2-0066/` | nginx `rbi-router` не отдаёт (`scripts`, `tests`, `ai-dev` уже в правиле) |

## 2. Что увидят люди (один раз — переход со старого кэша приложения 18.104.1)

- Старый кэш приложения сам заметит новый `sw.js`, новая версия скачается целиком в фоне (≈ 32 МБ один раз; дальше — только изменённые файлы).
- **Первое открытие** после выкладки может ещё показать прежнюю версию (у части людей — синюю плашку «Доступно обновление»: её можно нажать или не нажимать); **со второго открытия** — новая версия целиком, строка версии в «Помощь и о программе». Стенд `r-transition`: за 2 открытия, без сети после перехода всё открывается.
- Неотправленные записи на устройстве не трогаются: уходят из новой версии (стенд `r-queue`: ровно 1 раз).

## 3. Шаги

1. Свежий `main` в ветку (если ушёл вперёд); `npm run build:version`, `npm run test:unit`, `npx tsc --noEmit`, `npm run build:platform`, `node tests/offline/run.mjs` (сценарии P2-0058, `w-offline w-tabs`, все `r-*`).
2. Слияние в `main` (fast-forward), push в `IgNiKoN/rbi-q`.
3. Сервер (панель Beget → терминал VPS «rbi-q supabase»): `cd /var/www/rbi-quality && git rev-parse HEAD` (запомнить) → `git pull --ff-only` → `git rev-parse HEAD` = коммит `main`.
4. Проверка без входа: `node scripts/check-release.mjs` — каждый файл описи на сайте совпадает с отпечатком (иначе у людей версия не поставится); `index.html` — без `RBI_APP_VERSION 18.59`.

**Как прошло 29.10.2026:** `main` `6d4f736` запушен, `git pull` в панели Beget (терминал VPS, `2ec8959` → `6d4f736`). Проверка сайта нашла: `.nojekyll` → 404 (nginx не отдаёт скрытые файлы) — новая версия у людей не ставилась бы (прежняя работала). Исправлено: скрытые файлы не входят в опись, стенд отдаёт их как nginx (404), сторож в unit; повторная выкладка — ниже в CHANGELOG / отчёте.

**Откат:** на сервере `cd /var/www/rbi-quality && git reset --hard <запомненный HEAD>`. Устройства: старый `sw.js` придёт как «новая версия» — новый кэш приложения поставит его по-старому (у старого кода — плашка «Обновить» или два открытия). Данные на устройствах не теряются.

## 4. Полевой тест владельца (телефон, 10 минут)

1. Открыть приложение с интернетом, закрыть, открыть ещё раз. «Настройки → Помощь и о программе» — вверху «Версия 2026.10.29-… от 29.10.2026 · это последняя версия».
2. Включить авиарежим, закрыть и открыть приложение — разделы (Качество, План/Факт, «Компания») открываются.
3. При следующей выкладке: через минуту-две в строке — «Новая версия скачана — включится при следующем запуске»; работать дальше — ничего не перезагружается; закрыть и открыть (или свернуть на 30+ минут и вернуться) — новый номер.
4. Если что-то не так: «Данные на устройстве → Журнал синхронизации → Скопировать отчёт для разработчика» (в отчёте — номер версии) и прислать.

**Не проверялось на настоящих iPhone / Android** (стенд — Chromium, подставной сервер).
