## Что сделано

1. **«☰» на экранах без шапки (ТД №174).** Причина: `showView()` План/Факта и `switchViewNode(…, false)` (Настройки, Аналитика, Инженер, БЗ) прячут `#main-header`, а мобильный переключатель модулей был только в ней. Теперь `ShellService.syncMobileModuleStrip()` (`js/core/app-shell.js`): шапка скрыта → та же `.mobile-module-menu-wrap` (кнопка «☰» и список, второго меню нет) переезжает в строку `#mobile-module-strip` над содержимым (`index.html`), рядом — название модуля; шапка видна → возвращается на прежнее место (комментарий-якорь). Проверка — наблюдатель стиля шапки и класса `body`, `hashchange`, `rbi:route`, `rbi:platform-access`, `resize` (через `setTimeout(0)`: `requestAnimationFrame` в фоновой вкладке не вызывается — строка «застревала», найдено на стенде). На ПК (≥ 768 px) строка скрыта CSS.
2. **Отметка модуля в списке**: на экранах План/Факта отмечен «План/Факт» (раньше — «Качество» по режиму); в Настройках — модуль, из которого пришли (`currentPlatformItem`). ПК-меню не менялось.
3. **Последний модуль после входа почтой**: `homePathFor(access, lastHash)` (`platform.service.ts`), `goHome()` (`entry.ts`) берёт `rbi_last_module_hash` роутера (Настройки туда не пишутся); модуль недоступен компании — как раньше: План/Факт, без него — Настройки. Повторное открытие приложения и раньше открывало последний экран (роутер, проверено на стенде).
4. SW `18.79.0`, «История обновлений», `CHANGELOG.md`, `docs/APP_GUIDE.md`. Пересобран `js/dist/platform/`.

## Доработка после показа (25.10.2026, владелец: «посмотри, чтобы нормально вписывалась на всех экранах»)

- Автообход 29 экранов на 375×812 (Качество, Стройконтроль, Стройконтроль в2, План/Факт — все подвкладки и Настройки каждого): на каждом «☰» видна и нажимается (не перекрыта), все пункты списка доступны, у экранов без шапки — строка с названием модуля. Прокрутки страницы вбок нет.
- Найдено и исправлено: плашка «Стройконтроль — бета» оставалась над План/Фактом после перехода из Стройконтроля (`planfact/index.ts` `showView` прячет; `app-mode-utils.js` — при возврате в Стройконтроль показывает). Проверено: Качество → Стройконтроль (плашка есть) → План/Факт (нет) → Стройконтроль (есть) → Качество / в2 (нет).
- Стройконтроль на стенде не был виден, потому что у тестовой компании стенда был включён только План/Факт + Качество: список модулей = модули, включённые компании («Администрирование»). На стенде включён — в списке «Качество, Стройконтроль, Стройконтроль в2 (тест), План/Факт». «База знаний» отдельным пунктом при входе почтой не показывается (P2-0016; отдельный модуль — решение владельца, P2-0028).
- По решению владельца в этой же задаче: «Сводка» План/Факта — ряд кнопок объектов был шире экрана (477 px при 375), правые обрезались. Причина — `.sm-filters` в узком виде колонка с `flex-wrap:wrap` (линия растягивается по самому длинному ряду). Исправлено `flex-wrap:nowrap`: ряд 311 px, листается, последняя кнопка доступна; ПК без изменений (1280 — строка с переносом).
- По просьбе владельца: «Стройконтроль в2» при первом входе — пустая полоса сверху. Причина — `updateBodyPadding` брал высоту шапки из кэша Качества (272 px вместо 59 px; правило «замер меньше кэша — берём кэш» защищало от анимации раскрытия). Исправлено: кэш свой у модуля, кэш главнее замера только пока шапка анимируется (`getAnimations`). Проверено: Качество → в2 → Качество → Стройконтроль → в2 → Качество: отступ = шапка + 15 px каждый раз; сворачивание шапки Качества при прокрутке — как раньше (287 px).
