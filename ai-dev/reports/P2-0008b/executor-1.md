- **Решения Исполнителя (на подтверждение при приёмке, ТД №55):** (1) в акт идёт весь принятый факт по дату «по», ещё не выставленный (карточка: «за период − выданное»; при непрерывных периодах результат тот же, иначе — не теряется невыставленный объём прошлых периодов); (2) цена работы = работа + материал строки КП (иначе акт дешевле КП); (3) материал без нормы — по отношению объёмов в ВОР; (4) выдача отклоняется, если после сохранения выдан другой акт по тем же строкам («пересохраните»).

## Пользовательский сценарий

1. Роль ПТО (или РП/экономист), проект с подтверждённым ВОР, сметой и редакцией КП, принятым фактом прораба.
2. «План/Факт → КС-2» → выбрать договорную КП → «Новый акт» → поправить объём строки и № договора → «Сохранить редакцию» → «Скачать Excel» → «Выдать» → «Новый акт».
3. Ожидаемо: строки заказчика с объёмами из факта и ценами КП; правка помечена; файл КС-2 открывается в Excel; во втором акте выданный объём — в «выставлено ранее». Загрузить свой бланк с метками → акт скачивается в бланке.
