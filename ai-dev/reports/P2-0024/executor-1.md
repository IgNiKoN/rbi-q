## Отступления от карточки (с основанием)

- **Этап 4 — изменён по решению владельца** (24.10.2026, кнопка «Безопасный вариант (рекомендую)»). Замер V8 с принудительной сборкой мусора (10 000 записей): удаление «тяжёлых» полей не экономит память (облегчённая запись на 7% тяжелее полной), а `details` читают геймификация (наличие комментария), ИИ (текст), отчёты (код причины). Сделано: одинаковые строки общим экземпляром (−16% памяти истории), содержимое записей то же — поэтому чтение полной записи из базы при открытии/правке/отправке не понадобилось (отправка и так читает из базы). Цель «≤ 50 МБ на 3000» недостижима: пустое приложение на стенде — 52 МБ.
- **«История» — список из памяти** (этап 5): старый код при свёрнутых объектах в фоне догружал из базы всю историю второй копией (заголовки объектов в итоге считали все записи периода). Новый берёт список из истории в памяти (`historyListFromMemory`, порядок = индекс `by_date`, проверено на 10 000) — заголовки = итог старой версии, второй копии нет.
- **Файлы вне перечня §4** (минимально, по необходимости): `js/services/sync/sync-progress.ui.js` (`setDetail` — проценты), `js/services/storage/checklist-snapshot.utils.js` (чистые функции снимка; без import в `storage-db.core.js` — тест `config.test.ts` загружает его как обычный скрипт), `js/services/storage/history-memory.utils.js` (разрешённая «облегчить проверку»), `index.html` (два тега модулей), `history.state.js`, `session.service.js`, `inspection.service.js`, `app-mode-utils.js` (места, где история попадает в память), `analytics.desktop.render.js` (ПК-раскладка ждёт второй шаг «Сводки» и строит тепловую карту до раскраски).
- **«≤ 40 запросов»** выполнено при лимите строк сервера ≥ ≈ 3600; фактический лимит не подтверждён (ТД №158). «≤ 15 с» выполнено и при лимите 1000.
- Задержка фильтров 300 мс: уже была одна перерисовка с задержкой 400 мс (`multi-filter.js`) — не менялась.

## Сценарий для владельца

1. Откройте Качество 2.0 на телефоне, обновите страницу дважды (SW 18.72.0). Первый запуск чуть дольше — один раз перестраивается база.

3. «История»: раскройте объект — появятся подрядчики и проверки; числа в заголовках — как раньше.
4. Новый телефон / удалить данные сайта и войти — история целиком за секунды с процентами.
