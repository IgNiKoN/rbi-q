## 2. Что увидят люди

- «Компания → Проекты → проект → Объекты и места»: в карточке этажа / квартиры — блок «План» (загрузить, открыть, заменить, снять, версии); PDF можно перетащить на строку этажа; несколько PDF — на корпус (лист «куда какой файл»); «есть план» в дереве, «▤» в шахматке.
- Качество, СК 2.0 — экраны те же; план приходит из «Компании». В справочнике Качества у мест «Компании» вместо «Загрузить PDF» — «Загрузить в Компании →».
- Все PDF в приложении открываются новой pdf.js (безопасность: CVE-2024-4367); первый экран легче на ~88 КБ.

3. **Сервер:** снимок базы (панель Beget) → SQL Editor: `055_place_plans_up.sql`. Проверка:

5. **Перенос:** `scripts/p2-0057/02_transfer.sql` (компания по умолчанию RBI; другая — `set p2_0057.company = '…';` перед скриптом). Сообщение: «создано документов N; пропущено: …».

## 4. Проверка владельцем (10 минут)

1. Компьютер: «Компания → Проекты → (проект «Компании») → Объекты и места» → раскрыть секцию → перетащить PDF на «эт. 5» → строка подсветилась, плашка «План «эт. 5»: версия 1», в строке «есть план».
2. В карточке «эт. 5» → «Заменить» другим PDF → «Версии (2)» → у № 1 «Сделать текущей» → «Открыть» — открылся первый файл.
3. Бросить на корпус 3–4 файла «Этаж 1.pdf», «2 этаж.pdf» → лист «куда какой файл» → «Загрузить» → «Отменить» снимает все.
4. Стройконтроль 2.0 → план «эт. 5» — новый план, точки замечаний на месте; Качество → «Осмотр» → точка на плане этого этажа — тот же план.
5. Телефон: карточка этажа → «Загрузить план» (выбор файла) → план появился; без сети в Качестве — план открывается, если был скачан («Данные на устройстве → Фото и PDF заранее»).
