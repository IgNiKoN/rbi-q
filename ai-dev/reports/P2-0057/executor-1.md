## Решения по ходу (в рамках карточки)

- **Форма ссылки-копии (этап 1, стоп-условие):** экраны Качества / СК открывают `pdf_url` через кэш приложения, который знает только `…/public/quality-…`. Копия пишет ссылку **той же формы** на бакет ядра; в `sw.js` одна строка — бакет ядра берётся так же (с входом). Экраны модулей не менялись. Сервер не знает свой внешний адрес — ссылку присылает приложение, сервер строго сверяет её с путём файла и наличием файла в Storage.
- **Имя файла версии** — `<id документа>.pdf` (а не номер версии): id с устройства, повтор после обрыва не создаёт дубль, гонки номеров нет.
- **Перенос** — ссылкой на прежний файл (SQL, без копирования файлов): ссылки в модулях не меняются; ТД 390.
- **Права** — единый механизм мест: читать — `core.is_project_participant` / `core.can_manage_projects`, класть — `core.require_places_manage` (через `core.can_manage_places` — тот же источник). Новых действий в матрице не понадобилось.
- **Старая копия на устройстве:** запись Качества / СК с прежней ссылкой ядра или без плана (статус помещения, имя этажа) проходит, план остаётся текущим; своя ссылка, пометка удаления, перенос — отказ 42501.
- **Попутно (тот же экран):** файл, перетаскиваемый над строкой дерева, показывал «нельзя» и не принимался (касалось и Excel P2-0056) — исправлено.
