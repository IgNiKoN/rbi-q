# P2-0034 этап 3 — настройки и все потребители callAI

**Дата:** 25.10.2026.

## Сделано
- Настройки → «AI-ассистент»: два способа — «По учётке» (`aiAuthMode = account`) и «Мой персональный API-ключ» (`personal`); «По роли» и «Корпоративный пароль» (поле пароля) убраны. Старые значения `role` / `corporate` показываются и работают как «По учётке» (`ai.state.js getAuthMode`, `settings.render.js`); поле ключа видно только при `personal` (раньше — по флагу `usePersonalKey`).
- `changeAiMode` без блока корпоративного пароля.
- Переводы (4 языка): `settings.body.ai.mode_account`, `quality.ai.error.login`, `quality.ai.error.unavailable`.
- SW `18.83.0`, «История обновлений».
- Потребители: задачи (`tasks.module.js _callAI`), геймификация (`game.actions.js _callAI`) и остальные (`RBI.services.ai.call`, ~15 функций: FMEA, совещания, СК, наставник…) — все через `window.callAI` → по учётке `pf-ai`. Кода в них менять не потребовалось.
