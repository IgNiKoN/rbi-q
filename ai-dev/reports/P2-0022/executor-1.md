## Пользовательский сценарий

1. Прораб: «Факт → Ввод» → место → «Внести факт» → окно (телефон — шторка). «Период» → «С», «По», объём, бригада → «Внести» → «Записано: … за период …»; «История» — «за период dd.mm–dd.mm».
2. РП / руководитель: «Сводка» → объект → «Виды работ»: прогноз окончания, Δ к финишу (позже — красным), % отклонения с заливкой; «Позиции по местам» — колонка «Прогноз»; «Скачать Excel» — те же колонки.
3. «ВОР → Позиции» → карточка позиции → блок «Прогноз».
