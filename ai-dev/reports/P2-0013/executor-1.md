## Решения Исполнителя (внутри карточки, на приёмку)

- Админ платформы «видит всё» — только в компаниях с включённым модулем (выключенный модуль закрыт для всех одинаково). В «одну проверку» вошли все 4 функции членства/прав + `pf_my_permissions`/`pf_my_company_access` (их прежний расчёт шёл мимо `has_permission`).
- Модуль доступен человеку, если включён у компании и у него есть хоть одно действие `<код>.*`.
- «Компания: …» — в полосе раздела и в «Настройки → Платформа» (шапка оболочки в «План/Факте» на телефоне скрыта); выбор меняет меню, данные «План/Факта» — по всем доступным компаниям, как раньше (ТД №88).
- Вкладка PIN в разработке — прежнее «облачный вход отключён»; кто уже подключён по PIN (облако Quality включено) — без экрана входа, сразу «Качество».
- Демо скачивает «План/Факт» (разбор ВОР внутри него) — ТД №90.

## Пользовательский сценарий

Откройте платформу → «Вход» → `demo-foreman` → в меню только «План/Факт» и «Настройки», подвкладки прораба. Выйти (Настройки → Платформа) → войдите своей почтой → «Настройки → Администрирование платформы» → выключите «План/Факт» у «Демо-компании» → `demo-foreman` после обновления видит «Модуль не подключён», в меню только «Настройки», файл модуля не скачивается → включите обратно. Сборка «выпуск» — `docs/SERVERS.md`.
