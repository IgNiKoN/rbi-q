# P2-0074 — план выкладки

**Что выкладывается:** только сайт (`js/core/router.js`, `js/dist/platform`, манифесты модулей, `sw.js`). **Миграций нет**, база не меняется.

## 1. До выкладки
- Владелец: «Архитектор. принято P2-0074» → влить ветку `task/P2-0074-welcome-home` в `main` (по разрешению владельца), `git push`.
- Если до влития в `main` попали другие блоки — пересобрать вход платформы и опись версии: `npx vite build --config vite.platform.config.ts && npm run build:version`.

## 2. Выкладка (владелец, терминал Beget)
- `cd /var/www/rbi-quality && git pull --ff-only`.

## 3. Откат
- `git reset --hard <прежний коммит main>` в `/var/www/rbi-quality` — данных не трогает. Отметка «приветствие было» на телефонах останется и ничему не мешает.

## 4. Проверка после выкладки (владелец, 5 минут)
1. Новая версия включится при следующем запуске или кнопкой «Перезапустить сейчас» в «Настройки → Помощь и о программе».
2. **Все, кто уже работает, один раз увидят приветствие** при первом открытии новой версии без адреса (отметки «приветствие было» у них ещё нет) — так задумано.
3. Телефон: закрыть и открыть приложение → «Добро пожаловать, <имя>», плитки появляются по очереди; нажать «Качество» → Осмотр.
4. Закрыть и открыть снова → сразу Осмотр (последний раздел), приветствия нет.
5. ПК: то же; на приветствии слева только боковое меню, сверху полоса с названием и пользователем.
6. Открыть ссылку на экран (например, на ВОР) — открывается ВОР, приветствие не мешает.

**Не проверено до выкладки:** живой телефон владельца и вход живой учёткой (стенд — подставные данные).
