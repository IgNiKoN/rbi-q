# RACI — RBI Platform (карточка старта)

> R = Responsible, A = Accountable, C = Consulted, I = Informed.  
> Цель матрицы: показать руководству, **кто за что отвечает**, и зафиксировать, что инициатор продаёт роль **владельца продукта / архитектора инициативы**, а не «единственного разработчика на энтузиазме».

## 3. Что явно не должен делать инициатор в одиночку

Чтобы предложение услуг было реализуемым, инициатор **не** должен оставаться единственным:

- разработчиком production-кода;
- администратором личных облачных ключей;
- единственным носителем паролей и промптов;
- единственной линией поддержки 24/7 без выделенной функции сопровождения.

Эти функции распределяются на техлида, разработку, ИТ и поддержку — иначе RACI формальный, а риск фактический.

## 4. Эскалация

`Разработка / пилот → Техлид / владелец процесса → Владелец продукта → Куратор → Руководство`
